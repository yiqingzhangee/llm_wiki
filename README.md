# llm-wiki

一个基于 `raw/ ➜ wiki/` 增量同步的**研究型知识库仓库**：把零散的原始资料（论文、报告、文章、代码、转录、视频）逐步编译成可持续扩充、交叉链接、可检索的结构化 wiki。

> 维护方式是"人放原始材料，Agent 持续织入"。本项目含一套 Agent 协作 schema（见 `CLAUDE.md`）。

## 仓库目标

- **不是**一次性的 RAG/问答池，而是要让知识在文件里**持续沉淀、更新与互链**。
- 人负责：往 `raw/` 放原始资料、探索、提问。
- Agent 负责：增量编译 `wiki/`（来源页、实体页、概念页、对照页、地图页），并保持索引与日志当前。
- 核心原则：
  - `raw/` 保存原始证据，**只读**（唯一例外是 `raw/search/` 的搜索归档）。
  - `wiki/` 统一使用**简体中文**。
  - 每次增量同步更新 `wiki/index.md`、追加 `wiki/log.md`。
  - 冲突、不确定性与证据边界要**显式标注**，不静默覆盖。

## 目录结构

```text
.
├── raw/                  # 原始资料（只读）
│   ├── articles/         # 文章 / 论文 / 代码等
│   ├── papers/
│   ├── transcripts/      # 转录稿
│   ├── code/             # 代码素材
│   ├── videos/           # 视频
│   └── search/           # 搜索结果归档（代理可写 .md）
├── wiki/                 # Agent 维护的结构化知识库
│   ├── sources/          # 来源页：逐篇资料总结
│   ├── entities/         # 实体页
│   ├── concepts/         # 概念页
│   ├── comparisons/      # 对照页
│   ├── maps/             # 导航 / 知识地图
│   ├── meta/             # 运行元信息 / schema 说明
│   ├── index.md          # 内容总索引
│   └── log.md            # 增量同步日志（仅追加）
├── CLAUDE.md             # 仓库协作与同步规则（Agent 读取）
└── README.md             # 本文件
```

## 基本工作流

### 1. 添加原始资料

把新的论文 / 报告 / 文章 / 代码 / 转录放入 `raw/` 下合适的位置。

注意：
- 同步过程中**不修改 `raw/` 已有内容**（包括"小修"）。
- `raw/` 视为原始证据层，保持不可变。

### 2. 执行增量同步

使用 `/wiki-sync` 命令，从 `raw/` 增量整理到 `wiki/`。

同步遵循 `CLAUDE.md` 中的规则，重点包括：
- `raw/` 只读；`wiki/` 用简体中文。
- **深度织入**：不只写来源页，还要同步更新 `entities/`、`concepts/`、`comparisons/`、`maps/`，补齐交叉链接。
- 更新 `wiki/index.md` 目录与一行摘要。
- 向 `wiki/log.md` **追加**记录（不改历史，不删旧条目）。

### 3. 检查输出

重点检查：
- 新增 / 更新的 `wiki/sources/*.md`。
- 相关概念页、实体页、对照页、地图页是否同步织入。
- `wiki/index.md` 是否更新。
- `wiki/log.md` 是否仅追加。
- 冲突与不确定性是否已显式标注。

### 4. 提交与合并

推荐流程（见 `CLAUDE.md` 的 Git 同步约定）：
1. 先在 `main` 上 `git pull origin main` 同步。
2. 新建**日期版本分支** `kb/<YYYY-MM-DD>-v<N>`（知识库发布）或功能分支（如 `docs/readme-usage`）。
3. 在分支上提交并 push。
4. 发起 Pull Request 到 **`main`**（`base: main`），审阅后合并。

## 编写与协作原则

- 以来源为依据，不凭空扩展结论。
- 明确区分**事实 / 推断 / 不确定项**。
- 对与既有结论冲突的内容**显式标注**张力，不静默改写。
- 保持可追溯性（来源页链接到 raw 路径）与可维护性。

## 常见约束

| 项 | 约束 |
|---|---|
| `raw/` | 只读；仅在 `raw/search/` 允许代理写归档 `.md` |
| `wiki/` | 统一简体中文；标识符/引用原文除外 |
| `wiki/log.md` | 只追加，不改写历史 |
| 织入深度 | 默认深度更新：sources + concepts + comparisons + maps + index + log |
| Git 发布 | 用 `kb/<date>-v<N>` 分支 → 合并到 `main` |

## 适用场景

- 论文与技术报告归档与持续跟踪。
- 研究主题深读、对比分析与路线图构建。
- 构建跨专题、可检索、可复用的知识网络。
- 团队 wiki（Slack/会议等来源，经人审阅后喂入）。
