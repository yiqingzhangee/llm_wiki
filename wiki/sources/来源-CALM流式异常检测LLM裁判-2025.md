# 来源：CALM — 连续自适应 LLM 中介的流式时序异常检测（2025）

- **原始路径**：[`papers/2508.21273.pdf`](../../raw/articles/time_series_agent/papers/2508.21273.pdf)（arXiv 2508.21273，Berkeley/Google，2025-08）
- **类型**：系统论文（流式架构 + 持续微调 MLOps）
- **同步日期**：2026-08-31
- **证据等级**：**E2**（含架构与基准；定量为作者报告口径）

## 一句话摘要

**CALM（Continuous, Adaptive, LLM-Mediated）** 把时序基础模型（**TimesFM**）嵌入**全自动自适应闭环**：用 **Apache Beam** 做高吞吐乱序流式处理，用 **LLM-as-a-Judge** 做在线语义概念漂移检测，用闭环持续微调让模型随漂移自适应——主张"通用基础模型 + 专门化自适应"合二为一，而非二选一。

## 三大贡献

1. **可扩展流式架构**：基于 **Apache Beam** 的端到端异常检测，支持高吞吐、乱序数据流，分布式有状态处理保正确性。
2. **LLM-as-a-Judge 机制**：新型在线语义漂移检测器——LLM 对异常做**带理由的判断**，区分瞬时噪声与真实分布偏移，指导模型适应（超出传统离线 LLM 评测范畴）。
3. **闭环持续微调管线**：全自动 MLOps——收集 LLM 判定为有价值的样本 → 触发微调任务 → 动态部署改进模型，无需人工干预应对概念漂移。

## 方法定位

- **范式**：预测式异常检测（forecasting-based）。模型从近期历史预测未来值，**预测残差**作异常分；超阈值判异。CALM 改进点：用模型**分位数预测**定义动态稳健阈值。
- **LLM 异常检测四分类**（CALM 归纳，见 §2.3）：① 直接提示（SigLLM Prompter，转文本查 LLM，弱于预测式）；② 预测式（SigLLM Detector，**CALM 采用**）；③ 表示与蒸馏（AnomalyLLM/Tri-LLM，LLM 当特征提取器/教师蒸馏）；④ 多模态（转图像用 VLM，如 VisualTimeAnomaly，对 range-based 异常稳健、抗缺失）。
- **时序基础模型景观**（Table 1）：TimesFM（decoder-only，patching）/ Chronos（值量化作语言建模）/ Moirai（encoder-only，any-variate attention）/ PatchTST（channel-independent patching）/ TimeGPT（商业，conformal prediction）。

## 实验与量化

- 基准：**TSB-UAD**；相对静态预训练基线有显著性能提升（ROC AUC，作者报告口径，未给具体数字于所读页）。
- LLM-as-a-Judge 区分噪声 vs 真实漂移，驱动持续微调。

## 冲突与不确定性

- "显著提升"未在所读页给具体 ROC AUC 数字，定量结论应回原文。

- 持续微调的算力/标注成本（虽称全自动）未充分披露。
