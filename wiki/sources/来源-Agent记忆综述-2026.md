## 一句话摘要

提出 **Foundation Agent Memory** 的统一三维分类法（**记忆基底 substrate / 认知机制 cognitive mechanism / 记忆主体 subject**），主张 AI 进入「下半场」后，记忆不再是被动存储，而是 Agent **自我演进、长时任务可用性**的核心承载层——从短提示走向跨会话、可治理、可学习的记忆系统。

## 核心分类法

### 1. 记忆基底（Substrate，"以什么形式存在"）

- **外部记忆（External）**：独立于模型参数的存储，显式 read/write。
  - **向量索引**：embedding + 近邻搜索（HNSW/IVF/PQ），RAG 的主流实现。
  - **文本记录**：持久化人工可读摘要 + episodic 时间线（如 MemGPT 式 core summary）。
  - **结构化存储**：关系表 / 图 / 树（知识图、树状摘要）。
  - **分层存储**：多模块（core/episodic/semantic/procedural/resource/knowledge），meta-memory manager 协调。
  - *取舍*：可扩展、易更新、跨会话持久；但检索延迟、依赖索引质量、随规模增长引入噪声 → 需 summarization/forgetting/pruning。
- **内部记忆（Internal）**：模型权重 / 推理时状态。
  - **权重（Weights）**：预训练/后训练/模型编辑/蒸馏写入参数；访问快但更新昂贵、易灾难性遗忘。
  - **隐状态（Latent-State）**：跨步复用 hidden states；会话内有效但不持久、随序列长度线性增长。
  - **KV Cache**：注意力键值缓存，加速自回归解码；研究热点是压缩（heavy-hitter 驱逐、按层定预算）。

基底间存在八维取舍表（检索延迟 / 存储成本 / 更新灵活性 / 上下文开销 / 跨会话持久 / 可扩展性 / 遗忘风险 / 检索精度）——内部记忆访问快但昂贵且易遗忘；外部记忆可扩展但检索质量敏感。

### 2. 认知机制（Cognitive Mechanism，"记忆如何起作用"）

借用人类认知模型五类：**感觉记忆 / 工作记忆 / 情景记忆 / 语义记忆 / 程序记忆**。工作记忆「守门」决定哪些经验进入并留存于活动上下文；长期记忆累积并固化为可复用知识与技能，二者构成 Agent 从自身经验中改进的闭环。

### 3. 记忆主体（Subject，"为谁服务"）

- **用户中心（user-centric）**：个性化、用户画像与偏好。
- **Agent 中心（agent-centric）**：自身经验、技能累积。

## 关键结论

1. **范式转向**：AI「下半场」重心从模型/榜单分数转向**真实长程效用**——长时、动态、用户依赖场景（agentic coding、deep research、computer use）中上下文爆炸超出固定窗口，记忆是弥合「榜单表现 vs 现实可用」差距的关键。
2. **记忆即自我演进的基底**：工作记忆筛选经验、长期记忆固化技能；记忆管理本身正成为**可训练、可演化**的能力——强化学习驱动的上下文策展、决策时经验固化、显式可移植可分享技能（经 agent harness / context engineering / 标准化工具中介协议外化）。
3. **学习策略谱系**：prompt 驱动（静态→动态）→ 微调参数化策略 → 强化学习（step-level 记忆决策）。
4. **单/多 Agent 操作**：单 Agent 的基础记忆操作 vs 多 Agent 拓扑下的记忆路由（与 [[多Agent系统研究趋势与工程映射]] 的协作拓扑主题呼应）。
5. **六大开放挑战**：持续学习与自我演进、多 Human-Agent 记忆组织、记忆基础设施与效率、终身个性化与**可信记忆**、多模态/具身/世界模型记忆、真实世界评测。
