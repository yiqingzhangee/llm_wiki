## §1 Introduction

论证 KD 从压缩技术演变为**能力迁移引擎**；指出主流 **off-policy** 蒸馏在自回归场景下的 **train–test 错配**（学生在静态数据上对齐教师，但推理时分布为自身生成轨迹），与模仿学习中的 **exposure bias** 类比。引入 **OPD**：学生在自身策略采样轨迹上请求教师反馈，并联系 DAgger 等理论动机。说明综述贡献：$f$-散度统一视角、三维分类、白盒/黑盒对比、工业与开放问题。

## §3 Taxonomy of On-Policy Distillation（三维分类）

### §3.1 Feedback Signal

- **Logit-Based**：逐 token 对齐全分布（如 GKD、MiniLLM、ToDi 等）。  
- **Outcome-Based**：标量奖励/RM/验证器，序列级优化（RLKD、DPO 系等）。  
- **Self-Play**：无外部教师或对比自生成与人类参考（SPIN 等）。

### §3.2 Teacher Access

**White-Box**（完整 logits）、**Black-Box**（仅 API 文本/偏好）、**Self-Distillation**（自举或特权信息教师变体）。

### §3.3 Granularity

**Token-Level**、**Sequence-Level**、**Hybrid/Adaptive**（PRM、步级监督等折中）。
