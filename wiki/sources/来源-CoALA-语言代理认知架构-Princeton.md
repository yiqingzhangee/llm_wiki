## 摘要

CoALA（Cognitive Architectures for Language Agents）是普林斯顿大学提出的一个概念框架，将认知科学和符号 AI 的经典理论（产生式系统、认知架构如 Soar）与现代 LLM 驱动的语言代理进行桥接。论文的核心类比是：语言模型可以视为“概率产生式系统”，而提示工程技术则扮演了“控制流”的角色。CoALA 将语言代理组织为三个维度——记忆（工作记忆 + 三种长期记忆）、动作空间（内部：推理/检索/学习 vs. 外部：落地）和决策过程（规划-执行循环）——并用该框架回顾性地组织了大量已有语言代理，前瞻性地识别出未充分探索的研究方向。这是目前将 LLM Agent 研究放入 AI 宏大历史脉络中定位的最具理论深度的框架性工作之一。

## 关键主张

1. **LLM 作为概率产生式系统**：产生式系统定义字符串重写规则 $X \to Y$，LLM 则定义了在给定输入 X 时对续写 Y 的概率分布 $P(Y|X)$。提示工程（零样本、少样本、检索增强、自我批判等）实际上定义了一系列产生式序列。这一类比为使用认知架构中的控制机制来设计语言代理提供了理论基础。

2. **四类记忆的显式划分**：
   - **工作记忆**：当前决策周期中激活的符号变量，是 LLM 输入/输出的枢纽，在多次 LLM 调用之间持续存在。
   - **情景记忆**：过往决策周期的经验（轨迹、事件流、输入-输出对），支持经验回放和基于案例的推理。
   - **语义记忆**：关于世界与自身的知识（类似 Wikipedia 的只读知识库，但代理也可写入新知识）。
   - **程序性记忆**：LLM 权重中的隐式知识 + 代理代码中的显式知识（推理过程、检索过程、落地过程、学习过程、决策过程）。

3. **动作空间的四类划分**：推理（读写工作记忆）、检索（从长期记忆读到工作记忆）、学习（向长期记忆写入）、落地（与外部环境交互：物理环境、对话、数字环境）。其中推理和检索服务于规划阶段，落地和学习是决策周期的最终输出。

4. **结构化的决策过程**：每个决策周期包含规划阶段（提议 → 评估 → 选择）和执行阶段，最终产生一个落地动作或学习动作。规划阶段可利用推理和检索进行多步模拟和迭代改进——这一结构化描述可以直接映射到工程侧的 Agent 循环设计。

5. **学习能力的层次化光谱**：从更新情景记忆（写入经验），到更新语义记忆（反思抽象），到更新程序性记忆（微调 LLM 参数或修改代理源码）。特别指出了“更新检索过程”和“更新学习/决策过程”是目前几乎未被探索的空白地带。

6. **前瞻性研究方向**：CoALA 识别出多个可操作的研究空白，包括决策与检索的系统集成、学习的元认知控制（代理自主决定何时学习）、记忆的修改与删除（去学习）、以及学习新的学习和决策过程（meta-learning）。

## 待验证 / 局限性

- CoALA 是一个概念框架而非可执行的系统实现，其提出的研究方向（如代理自主更新学习/决策过程）目前仍处于理论设想阶段。
- 论文将 Soar 等经典认知架构中的概念直接映射到 LLM Agent 上，这一映射的完备性和边界条件仍需更多经验验证。
