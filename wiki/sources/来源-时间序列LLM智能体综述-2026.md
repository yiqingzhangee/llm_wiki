## 一句话摘要

综述提出 **LLM-for-Time-Series 的"问题驱动"分类法**：把系统按所解决的时间序列问题归为四类（**预测与推理 / 增强与合成 / 异常检测与诊断 / 决策支持**），并以**架构 / 工具 / 记忆**三个设计维度贯穿——主张 LLM 在时序场景的价值不在"当模型"，而在作为**会规划、调工具、维护记忆**的 Agent，处理演化观测与多步决策。

## 综述核心分类法

### 问题驱动四分类（Figure 3 taxonomy）

| 问题类 | 代表系统 |
|--------|---------|
| **预测与推理** | TimeSeriesScientist、TimeX、TimePAL、TS-Agent、TS-Reasoner、ZARA、CLIMATEAGENT、FETA |
| **增强与合成** | TESSA、ChatTS、BRIDGE |
| **异常检测与诊断** | AD-Agent、ARGOS、CALM、SAGE、LEMAD、AgentFM、LLM-TSD |
| **决策支持** | EchoAgents、FinMem、FinCon（交易）；Open-TI、LLMlight、Traffic-R1（交通）；Grid-Agent（电网） |

### 三个设计维度

1. **架构**：单 Agent；多 Agent（协作 / 竞争 / 混合）。竞争式 = 多 Agent 产替代假设后由打分/排序/投票/辩论/裁判裁决。
2. **工具**：数据库 API、检索 API、数据处理工具（含 DTW）、统计/ML 模型、模拟器/求解器/优化器——工具提供"参数化知识不可靠地给出"的可验证反馈。
3. **记忆**：**证据日志**（中间决策痕迹）/ **模式库**（可检索历史案例与典型片段）/ **分析策略**（可复用的"如何分析"经验）。

### 关键边界（定义）

综述把"时序 LLM Agent"严格界定为：LLM 必须做出**至少一个改变多步时序工作流的决策**（选动作/工具、更新记忆、修正假设、协调阶段）。**明确排除**：一次性 prompting、LLM 仅作静态编码器或事后解释器、非时序约束的通用 Agent。

## 子论文要点（异常检测与诊断为主，已逐篇深读建独立来源页）

- **AD-Agent**（USC/CMU/ASU，arXiv 2505.12594）→ [[来源-AD-Agent多Agent异常检测-2025]]：7 Agent + 短/长期记忆，自然语言→可执行 AD 流水线，集成 PyOD/PyGOD/TSLib；成功率 100%/91.1%/90%；**开源** `github.com/USC-FORTIS/AD-AGENT`（BSD-2）。
- **ARGOS**（UW/Microsoft Research，arXiv 2501.14170）→ [[来源-ARGOS自主规则时序异常检测-2025]]：LLM **训练期**生成可解释可复现 Python 规则，运行时不调 LLM；三 Agent + 模型融合；KPI +9.5% F1 / Yahoo +4.8% / 内部 +28.3%；未明确开源。
- **CALM**（Berkeley/Google，arXiv 2508.21273）→ [[来源-CALM流式异常检测LLM裁判-2025]]：Apache Beam 流式 + TimesFM 分位数预测；**LLM-as-a-Judge** 漂移检测 + 闭环持续微调；TSB-UAD 优于静态基线。
- **SAGE**（Korea Univ/SNU，arXiv 2605.05725）→ [[来源-SAGE专家式多Agent时序诊断-2026]]：5 阶段管线 + 4 专门分析器（9 类异常归 4 族）+ 合成 ICL（k-medoids + DTW top-3）；LLM 打分 0-100 归一化 temperature=0。
- **AgentFM**（北大/阿里，FSE'25，arXiv 2504.06614）：分布式数据库**角色感知故障管理**，LLM 多 Agent 编排，区分系统/数据/任务角色；用 Apache IoTDB 初步验证。
- **IoT 异常检测**（arXiv 2510.03859）：关键 IoT 基础设施异常检测，LLM + Agent 做上下文推理，注意力/记忆缓冲/语义推断提升可解释性，在智能电网/医疗仿真场景评估。

## 冲突与不确定性

- 综述"问题驱动分类"明确区别于按设计维度分类的既有工作，但二者在文献上重叠——同一系统常横跨多类，归类以"主要解决的问题"为准，存在主观判断。
- 子论文量化口径各异（ARGOS 公开+9.5% vs 内部+28.3%；CALM 用 ROC AUC；SAGE 用 benchmark 排名），**不可直接横比**。
- raw 含知乎体中文导读与智谱译文合集，可能存在转述偏差；技术细节以 arXiv 英文原文为准。代码 `llm-tsfd_code/` 仅含 constants/数据 CSV，非完整可运行项目，宜作数据样例参考。
