- **原始路径**：[`2505.12594v1.pdf`](../../raw/articles/time_series_agent/2505.12594v1.pdf)（arXiv 2505.12594，USC/CMU/ASU，2025-05）

- **同步日期**：2026-08-31
- **证据等级**：**E2**（含实验表与开源仓库；定量为作者报告口径）

## 一句话摘要

**AD-Agent** 把自然语言指令转成可执行的异常检测流水线：7 个专门化 LLM Agent（Processor / Selector / Info Miner / Code Generator / Reviewer / Evaluator / Optimizer）经**短期共享记忆 + 长期缓存记忆**协调，集成 **PyOD（多元）/ PyGOD（图）/ TSLib（时序）** 三大 AD 库，端到端跨模态构建可运行脚本。

## 方法要点

### 七个 Agent 分工

- **Processor**：解析 CSV/MAT/自然语言等异构输入，推断模态与监督类型，提取约束，结构化后供下游。
- **Selector**：据模态/任务选 AD 库；用户未指定模型时用 LLM 知识推荐（受 LLM 模型选择研究启发）。
- **Info Miner**：从长期记忆或 web 检索模型文档/用法（非专家最难的一步）。
- **Code Generator + Reviewer**：生成器写脚本；审查器用 LLM 合成样本做 dry-run，捕获执行错误，迭代修正至可运行（常见修复：缺参、错参、错导入名，如 DeepSVDD 缺 `n_features` 触发 TypeError）。
- **Evaluator + Optimizer**（可选）：有标签时跑流水线总结结果；Optimizer 做 LLM 驱动超参调优。

### 记忆设计（直接对应 [[Agent记忆系统与自我演进]] 的基底分类）

- **短期记忆**：会话级共享工作区，存用户输入/处理后的数据/选中模型/参数配置——对应**工作记忆**。
- **长期记忆**：缓存 Info Miner 的模型信息，避免重复昂贵 web 检索，周期性刷新（如每周）——对应**语义记忆**的向量/文本记录基底。

## 实验与量化

| 库 | 成功率 | 平均时延 | In/Out Tokens | 成本(USD) |
|----|--------|---------|---------------|-----------|
| PyOD | 100.0% | 24.0s | 3,272/667 | $0.015 |
| PyGOD | 91.1% | 19.6s | 3,143/673 | $0.015 |
| TSLib | 90.0% | 125.2s | 2,680/561 | $0.012 |

- **模型选择**：o4-mini 推荐，每数据集查 3 次取均值 AUROC；LLM 推荐显著超平均基线、多数数据集贴近最佳模型。
- **长期记忆效率**：web 检索约 10s/$0.035 每次调用；长期记忆检索近乎瞬时、无额外成本。
- **失败模式**：未处理的内部数据约束（如 PyGOD 的 GAAN 需二值目标）、库不一致（DOMINANT 导入失败被排除、TSLib 的 Pyraformer 输入尺寸不匹配）→ 需更强数据校验/类型检查/版本检查/回退。

## 开源实现状态

- 仓库：`https://github.com/USC-FORTIS/AD-AGENT`，**BSD 2-clause License**。
- Agent 用 GPT-4o 构建，模型选择用 o4-mini。
- 未来方向：更多库/模态、对话式迭代、预配置云工作区、成本感知规划、社区生态。

- 成功率/成本为作者报告口径，GPT-4o/o4-mini 价格与版本随时间变化，复现需对齐模型版本。

- ChatGPT 仅用于文稿语法润色（伦理声明），不影响方法。
