## 内容摘要

该文档按“单智能体编排框架、多智能体协作框架、平台与协议”三层梳理 Agent 生态，重点涉及 LangGraph、LlamaIndex、Semantic Kernel/MAF、AutoGen/AG2、CrewAI、OpenAI Agents SDK、MCP、Dify、Coze、Google ADK 等，并给出不同范式（ReAct / Plan-and-Execute / Function Calling / Workflow-based）的适用边界。

## 可提取的关键结论

- **生产场景主流路线是“确定性工作流 + 局部自主推理”的混合范式**，而非纯自主 Agent。
- **MCP 的价值在于连接层标准化**：跨工具、跨框架复用能力提升，减少 M×N 集成成本。
- **框架选型应围绕组织约束**（语言栈、合规要求、可观测要求、上线效率）而非“功能清单对比”。
