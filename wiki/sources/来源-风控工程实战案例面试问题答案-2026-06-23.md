## 摘要

该文档以面试问答形式，系统复盘了作者在字节跳动国际化电商风控和 TikTok 短视频社区内容风控两条核心业务线的完整项目经验。涵盖 200+ 异构模型体系搭建、双 Runtime Agent 架构设计、色情闪帧专项治理、团伙挖掘跨场景迁移、风险感知大盘架构设计等核心主题，附带大量可量化的业务指标（风险率下降 90%+、资损率 <0.3%、举报下降 34%、新用户风险率下降 80% 等）。

## 关键主张

### 电商风控

1. **200+ 异构模型体系**：整合设备/账号/IP/地址/团伙/行为等多维数据，首次上线风险识别扩招 10 倍，常态化月扩招 30%，准确率 >90%。
2. **三层防御体系**：事前预警 + 事中拦截 + 事后追溯，100+ 实时特征 + 1000+ 离线特征，300+ 套实时策略与模型。
3. **大模型辅助风控**：40B 大模型 + 动静结合提示词清洗风险地址（风险订单占比提升 50%+），XLM-R 小样本持续学习（地址风险降低 45%）。
4. **团伙挖掘**：半监督团伙检索模型 + motif 图模型精准打击黑产，新用户风险率下降 80%。

### 内容风控

5. **双 Runtime AI Agent 架构**：线上 pydantic-ai + Orchestrator-Worker 架构（串行短路 + 并行 Strictest-Win），离线 Durable Queue + Lease/Heartbeat 心跳保活，Token 成本优化 40%。
6. **色情闪帧专项治理**：粗筛+精检分层抽帧、动态密度调控、多帧特征融合、Dinvo2 小样本模型，用户举报下降 34%，日均处罚 6000+ 账号，48 小时全量止损。
7. **相似帧去重多级联动**：aHash/dHash（粗筛）→ pHash（主力匹配）→ ORB（对抗精判）→ 深度语义 Embedding（重度二创）。
8. **pHash 核心技术栈**：DCT 变换 → 保留低频 8x8 → 均值二值化 → 64 位哈希指纹，对抗缩放/裁剪/压缩/轻度调色鲁棒性强。
9. **团伙挖掘跨场景迁移**：从支付风控（资金流图）改造为内容风控（设备/IP/行为/内容多维度异构图），保留图挖掘 + 深度学习底座，四层全量改造。
10. **五层统一风控大盘架构设计**：数据接入层 → 特征中台层 → 感知模型层 → 策略决策层 → 运营运维层，通用能力下沉中台，差异化能力插件化。
11. **样本回流全流程**：4 大数据源 → 分层降噪 → 标准化 → 分池分发 → 多级质检 → 分区入库，应急通道最快数小时完成 0day 风险闭环。
12. **pydantic-ai 选型理由**：轻量化（vs LangChain 组件冗余）、原生 Pydantic 强类型校验、适合风控策略高频迭代。
