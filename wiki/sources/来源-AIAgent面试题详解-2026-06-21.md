## 内容摘要

该文档围绕 AI Agent 面试高频问题进行系统讲解，覆盖：

- Agent 基础概念（与 Prompt Chain / RAG / ChatBot+插件的边界）；

## 可提取的关键结论

- **入门学习上，Agent 工程的核心是“闭环执行”而非“多轮聊天”**。
- **工程落地上，工具调用、记忆分层、可观测性与异常处理是稳定性的关键约束。**
- **方法论上，单 Agent 与多 Agent 不应先验二选一，应根据任务复杂度与治理成本做分层。**
