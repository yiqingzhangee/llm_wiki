# 来源：SAGE — 专家式多 Agent 时序异常诊断框架（2026）

- **原始路径**：[`papers/2605.05725.pdf`](../../raw/articles/time_series_agent/papers/2605.05725.pdf)（arXiv 2605.05725，Korea Univ/首尔大学/Mirae Asset，2026-05）
- **类型**：方法论文（多 Agent + 合成 ICL）
- **同步日期**：2026-08-31
- **证据等级**：**E2**（含架构图与实验；定量为作者报告口径）

## 一句话摘要

**SAGE（Specialized Analyzer Group for Expert-like Detection）** 把单变量时序异常检测**重构为结构化诊断**：5 阶段管线（输入→双表示→4 专门分析器→证据驱动 Detector→诊断报告），把 9 类异常归 4 族交由专门分析器并行检查，用**合成 ICL**（从正常段构造对比样本，DTW 检索）做证据支撑，Detector 用 LLM 打分（0-100 归一化、temperature=0）产置信度。

## 方法要点

### 五阶段管线

1. **输入**：单变量时序 X=(x₁…xₙ)。
2. **双表示**：原始序列（供数值工具精确计算）+ 压缩摘要（含统计量、整数化代表样本、分段摘要、极值保留索引，供 LLM 高效提示）——省约 **75% token**。
3. **多分析器**（4 族 9 类）：
   - **PointAnalyzer**（蓝）：全局/上下文点异常，离群检测 + 滚动统计。
   - **StructAnalyzer**（绿）：趋势/均值/方差变化，分解 + 变点检验 + 分段比较。
   - **SeasonAnalyzer**（橙）：振幅/季节性异常，自相关 + 频谱 + 时频分析。
   - **PatternAnalyzer**（紫）：模式偏移/波形失真，符号化 + 递归方法。
   - 辅助视觉/模式证据工具：GAF、MTF、递归图、符号表示。
4. **证据驱动 Detector**：聚合 4 分析器输出 + 诊断可视化 V + 检索的合成 ICL 参考 R，产异常区间/类型/置信度。置信度按 rubric：LLM 对证据强度打 0-100 整数再归一化，考虑异常幅度、统计显著性、分析器间一致性、冲突证据——**重证据质量而非同意数**，temperature=0 保确定性。
5. **诊断**：Supervisor Agent 生成分析师导向报告（告警级别、时序特征、告警理由、建议动作）。

### 合成 ICL（核心创新）

- **离线**：从**正常参考段**提取代表性子序列（k-medoids 聚类）→ 对每个原型做**规则注入 9 类异常** → 构造正常-异常对比样本库。
- **关键约束**：标签仅用于参考池构建，**不**提供真实异常样本、不泄露异常类型监督、不涉及测试集信息。
- **在线**：对输入查询窗用 **DTW + LB_Keogh 剪枝**检索 **top-k=3** 最相似正常原型，供 Detector 置信度评分与异常类型排序。

## 输出形式

异常记录集 Y={(sⱼ, eⱼ, cⱼ, τⱼ, dⱼ)}：起止索引、置信度 c∈[0,1]、候选类型集、诊断证据。

## 与现有 wiki 的关系

- 对应 [[时间序列LLM智能体分类法]] "异常检测与诊断"类；专门分析器分工是综述"架构（单 Agent 内多角色分解）"+"工具（数据处理/统计-ML）"维度的实例。

## 冲突与不确定性

- 9 类异常归 4 族的映射是作者设计选择，非唯一正解；不同领域异常族划分可能不同。
- 合成 ICL 依赖"规则注入"能覆盖真实异常形态——若真实异常超出 9 类，检索参考会失效。
- LLM 打分虽 temperature=0，但仍依赖 LLM 对证据的理解，rubric 设计是隐性偏差源。
- 具体检测性能数字未在所读页给出，应回原文。
