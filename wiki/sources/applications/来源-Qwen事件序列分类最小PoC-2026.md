## 核心结论

事件序列分类的最小可行路线应先验证**信息是否有价值**，而不是先改造 Qwen 主干：固定预测时点，将可见事件按确定性模板序列化，使用分类头读取最后一个非 padding token 或明确的池化位置，并与 Dummy、逻辑回归、LightGBM、GRU 等强基线在相同数据切分和预算下比较。

## 数据与评测契约

- 每个字段区分 `event_time` 与 `available_at`；仅允许 `available_at <= prediction_cutoff` 的信息进入样本。
- 先完成时间切分与实体隔离，再在各分区构窗、插补、拟合标准化参数；标签成熟期和回溯修订应单列审计。
- 对短序列至少测试历史长度、顺序打乱、数值置乱、文本移除和读出方式，判断模型究竟使用了顺序、数值还是语言描述。
- 同时报 AUC/PR-AUC 与 Brier、ECE、最差桶、真实硬件延迟和成本；任何预设的 AP/Brier 增益阈值只是项目门槛，不是学术定律。

## 停止条件

若新增模态、顺序或 Qwen 微调未在多个时间外窗口带来稳定增益，或增益无法覆盖校准、尾延迟和维护成本，应停止复杂化并保留 GBDT/GRU/规则路径。对固定闭集分类，生成“高风险”等标签文本通常不如直接输出分类 logits 可控。

## 不确定性

- 模型接口能够处理分类输入，只证明张量与任务头可实现；不能推导业务效果、替代价值或上线可行性。
- 64/256/512 等长度阶梯与具体指标门槛需按数据规模、序列语义、硬件和错误成本重设。
- 本来源讨论静态模型/PoC，不应并入 [[时间序列LLM智能体分类法]] 的 Agent 定义。
