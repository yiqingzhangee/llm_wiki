# 来源：LUMOS 多模态用户行为预测（2026）

## 来源信息

- 论文：[LUMOS: Large User MOdel Series for Multi-Task User Behavior Prediction](https://arxiv.org/abs/2512.08957)，arXiv v2，2026-01-23
- 来源等级：作者公开论文，按 **E3** 使用
- 发布状态：论文公开；截至 2026-10-28 未发现官方代码或权重

## 输入与任务

LUMOS 把用户行为预测改写为多变量时间序列生成。每个历史时间点包含：

- 用户活动统计向量；
- 当日事件上下文；
- 静态用户属性。

未来已知事件单独作为条件。模型输出未来多个时间点的行为向量，每个向量同时包含分类与回归目标。

## 编码器

三种输入分别经独立 MLP，论文实验使用两层。静态 embedding 在各时间点复用，随后与当日行为、事件 embedding 拼接，再经投影 MLP 形成 daily token。历史 daily token 加时间编码后进入 Transformer encoder，自注意力学习长周期模式。

decoder 不使用 self-attention。每个未来事件 token 直接通过 cross-attention 查询历史 encoder 输出，再由投影头产生该日的多任务行为预测。这使不同未来时间点不会在 decoder 内相互泄漏。

## 证据边界

- LUMOS 的“多模态”指连续行为、事件上下文和静态属性，不是图文 VLM。
- 论文数据来自单一工业平台，规模和线上结果不能直接迁移到其他业务。
- 论文公开不等于模型可下载；本次未找到官方代码或权重。
