## 一句话主张

NSA 是**硬件对齐、原生可训练**的稀疏注意力：用"动态分层稀疏 + 粗粒度 token 压缩 + 细粒度 token 选择"在保持/改善性能的同时显著降低长上下文计算，且可端到端训练。

## 机制要点（视频：压缩/选择/滑窗三支并行）

- **三支并行稀疏分支**：粗粒度 token 压缩（全局）、细粒度 token 选择（局部、按相关性挑选）、滑窗（近期信息），配合可学习门控聚合。
- **硬件对齐**：避免不规则访存，使实现能在现代硬件（GPU）上获得实际加速，而不只是理论复杂度降低。
- **端到端训练**：直接以稀疏结构预训练，64k 序列上 decode / forward / backward 三阶段相对 Full Attention 都显著加速。
