## 一句话摘要

该报告主张：**ViT 视觉头决定“模型能看见什么”，但不决定整条风控链路最终收益**。在开放多模态模型选型中，应把**视觉头能力、整模型表现、风控系统 KPI** 三层拆开评估；内容审核、文档一致性核验适合优先试点，而身份真实性、支付交易裁决仍应由专模、规则、图模型和人工掌握最终权限。

## 核心结论

### 1. 视觉头决定输入保真上限，但不能单独解释业务收益

报告把“ViT 视觉头”定义为一整套视觉前端：图像预处理、视觉编码器、位置编码、切片 / 原生分辨率策略、连接器和视觉 token 压缩。它直接影响三类中间变量：

- 小字、局部目标与异常细节是否还可辨认；
- 二维布局与跨区域关系是否保留；
- 进入语言模型的视觉 token 数、时延与显存成本。

但从风控角度看，**最终 Recall / FPR / 损失 / 人审量**还同时受 OCR、检测专模、规则、图模型、阈值、人工复核和流量分布影响，因此不能把生产结果简单归因于 ViT。

### 2. 视觉路线已经从“固定视觉塔”分化到“动态分辨率 / 动态切片 / 自适应压缩”

报告梳理了开放 VLM 的几条主路线：

- **固定视觉塔 + 切片扩容**：LLaVA、Idefics、MiniCPM-V 等，优势是实现成熟，代价是 tile 数增长会线性抬高成本。
- **专用大视觉塔 / 多塔**：InternVL、NVLM、CogVLM、Eagle、Cambrian 等，强调更强视觉容量或互补特征，但视觉侧 FLOPs、显存和依赖显著增加。
- **原生动态分辨率 / NaViT 路线**：Qwen2-VL、Qwen2.5-VL、Qwen3-VL、Ovis2.5、Pixtral 等，减少切片边界损失，但必须显式管理 token 波动与批处理方差。
- **视频时空编码路线**：Qwen-VL、GLM-V、MiniCPM-V 4.5、Molmo2、NVILA 等，重点不在视觉塔名字，而在时间采样、时间编码与总 token 预算。

### 3. 榜单领先不能直接指导采购

报告反复强调几个评估陷阱：

- thinking / non-thinking、prompt 模板、工具调用、像素预算、量化方式都可能改变排序；
- 同一家族不同 checkpoint 的视觉前端并不一致，不能用一个“家族名”概括；
- benchmark 总分不能外推为生产 Recall、FPR 或 ROI。

因此，公开榜单只能帮助形成**候选短名单**，不能替代同业务输入、同部署条件、同阈值下的对比验证。

### 4. 生产线上量化 KPI 稀缺，尤其是支付交易反欺诈

报告区分了三层证据：

- **线上 A/B / 生产验收**：最强，但公开很少；
- **业务离线集**：能说明接近业务分布下的效果，但仍不能直接当线上收益；
- **公开 benchmark**：适合比能力，不适合定阈值。

它指出：

- 内容审核、品牌安全、文档核验已有少量生产或准生产案例；
- 退款欺诈、证件防伪等高对抗任务仍暴露明显漏检；
- **支付交易反欺诈** 几乎没有能够直接归因给 ViT 视觉头的公开线上指标。

## 风控落地建议

### 适合优先试点的场景

- **静态内容审核 / 广告合规**：可让专用 Guard 做主筛，通用 VLM 做隐含语义与二审。
- **文档抽取与一致性核验**：OCR 提供事实层，VLM 负责跨页语义、异常解释与多图证据整理。
- **退款与商品证据二审**：可把 VLM 作为多图语义理解层，但伪造检测仍需专模。

### 不宜让 VLM 主裁决的场景

- **证件真实性 / 活体 / 防伪**：局部篡改、全息、动态安全特征仍依赖专模与人工。
- **纯支付交易反欺诈**：如果主要信号是交易、行为与关系图，不应为了追逐多模态榜单而硬引入 ViT。

### 推荐的系统分工

- OCR / 检测专模：产出结构化字段、坐标、局部伪造信号；
- VLM：做跨区域、跨模态的开放语义归纳；
- 规则 / 图模型：承担确定性裁决与账户行为关联；
- 人工复核：接收高影响、低置信、证据冲突和疑似注入样本。

## 冲突与不确定性

- 报告本身整合了大量模型卡、厂商案例与论文，**证据层级不均**：技术路线结论较稳，生产收益结论需谨慎。
- 不同模型的视觉头、连接器、压缩器、时序编码和推理模式差异很大，不能用“开源多模态模型”做粗暴横比。
- 部分生产案例缺样本量、基线、阈值、组件消融或独立审计，适合作为“流程价值”证据，不适合作为精确 ROI 结论。
- 文中提到的许可、商用与训练数据限制具有版本敏感性；若后续真做采购或部署，必须回模型卡逐项核验。
