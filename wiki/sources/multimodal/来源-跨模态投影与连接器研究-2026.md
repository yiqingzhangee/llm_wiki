# 来源：跨模态投影与连接器研究（2026）

> 调研日期：2026-10-21。本文汇总公开论文与作者项目页，作为 [[多模态大模型跨模态投影与连接器]] 和 [[跨模态连接器实现方案对照-2026]] 的证据入口。

## 调研问题

多模态大模型中的 projector / connector 究竟承担维度变换、token 压缩、信息选择还是语义对齐？简单线性层或 MLP 何时足够，查询式压缩、空间聚合、深层交叉注意力和统一 token 路线又在什么条件下更合理？

## 核心结论

1. **投影不等于语义对齐。** 同名反证论文在 LLaVA-1.5 的闭集分类实验中发现，只微调 projector 可以改善任务，但投影后的视觉表征并未因此在线性探针中呈现更丰富的领域属性；作者据此认为相关属性主要由 LLM 参数建模。该证据反驳的是“projector 单独完成语义搬运”的强解释，不是否认接口的作用。
2. **最重要的设计变量常是保留还是压缩。** 一对一映射保留 patch 细节但增加上下文成本；查询式或池化式连接器减少 token，却可能丢失局部、空间和长尾证据。
3. **复杂度本身不是收益来源。** MM1 的受控实验认为视觉 token 数和分辨率影响最大，所比较 connector 类型影响较小；LLaVA-1.5、MiniGPT-4、VILA 也表明小型 linear / MLP connector 可以很有竞争力，但结论依赖是否更新 LLM、视觉前端和训练数据。
4. **复杂 connector 在特定场景更有理由。** 强压缩、高分辨率、多视觉塔、跨尺度聚合以及需要跨 decoder 层重新访问视觉证据时，Honeybee、TokenPacker、Cambrian-1 等路线提供了结构性方案。
5. **“无 projector”通常只是取消独立连接器。** Fuyu / SOLO 仍有连续 patch embedding；Chameleon / Emu3 把瓶颈前移到离散视觉 tokenizer。任何路线都需要某种模态表示转换。

## 正方证据：为什么保留独立连接器

| 论点 | 代表证据 | 适用边界 |
|---|---|---|
| 复用冻结的强视觉编码器与 LLM | BLIP-2、MiniGPT-4、LLaVA | 配对数据或训练算力有限，希望缩小可训练参数 |
| 固定视觉 token 预算 | BLIP-2 Q-Former、Flamingo Perceiver Resampler | 长上下文、视频、多图输入 |
| 保留局部性并可控压缩 | Honeybee、TokenPacker、DeCo | OCR、文档、图表、小目标 |
| 聚合多视觉塔与高分辨率特征 | Cambrian-1 SVA | 多编码器、跨尺度视觉系统 |
| 模块化替换、缓存和分阶段训练 | LLaVA、BLIP-2 | 工程迭代和独立版本治理 |

## 反方证据：为什么不能神化 projector

| 论点 | 代表证据 | 否定的强主张 |
|---|---|---|
| 任务提升不等于投影后表征完成语义对齐 | *Cross-Modal Projection... Doesn't Really Project...* | “projector 把视觉属性完整搬到文本空间” |
| 分辨率和 token 数可能比 connector 类型更重要 | MM1 | “换更复杂 connector 就是主要增益来源” |
| 查询压缩可能造成双重语义抽象 | DeCo | “先由 connector 挑语义一定优于保留 patch” |
| 简单映射在多种训练设置下有竞争力 | LLaVA-1.5、MiniGPT-4、VILA | “projector 越深越好” |
| 统一主干可取消独立 connector | SOLO、Chameleon、Emu3 | “独立 connector 是多模态模型必要模块” |

## 关键论文与可核查结论

### 基础接口与冻结两端

- [LLaVA](https://arxiv.org/abs/2304.08485)：以单个可训练矩阵把 CLIP 网格特征映射为语言 embedding token，先训练接口，再做视觉指令微调。
- [LLaVA-1.5](https://arxiv.org/abs/2310.03744)：两层 MLP 相对原始 linear projector 有小幅改进，说明简单非线性接口可作为强基线。
- [BLIP-2](https://arxiv.org/abs/2301.12597)：以 32 个查询和约 188M 参数 Q-Former 连接冻结图像编码器与冻结 LLM，并配套图文对比、匹配和生成目标。
- [Flamingo](https://arxiv.org/abs/2204.14198)：Perceiver Resampler 将可变视觉特征压为固定数量 token，再通过门控交叉注意力注入冻结语言模型。
- [MiniGPT-4](https://arxiv.org/abs/2304.10592)：在 EVA-CLIP + Q-Former 前端后使用单个 projection layer 接入 Vicuna；不能把它误读为“单层投影替代完整视觉连接器”。

### 保真、压缩与空间结构

- [Honeybee](https://openaccess.thecvf.com/content/CVPR2024/html/Cha_Honeybee_Locality-enhanced_Projector_for_Multimodal_LLM_CVPR_2024_paper.html)：把可控 token 数和局部上下文保真作为 projector 的两项关键属性。
- [DeCo](https://arxiv.org/abs/2405.20985)：先用自适应平均池化做空间压缩，再线性映射，减少查询式连接器的提前语义抽象。
- [TokenPacker](https://arxiv.org/abs/2407.02392)：采用粗到细注入，在作者的 LLaVA-1.5 设置下把 576 个 token 压到 144 或 64，并维持或改善所测基准。
- [Cambrian-1](https://arxiv.org/abs/2406.16860)：SVA 动态聚合多视觉编码器和高分辨率特征，强调空间对应和强压缩下的信息访问。
- [Preserve or Compress](https://arxiv.org/abs/2410.06765)：统一比较表明，保留型连接器在细粒度感知上更强；压缩型连接器在粗粒度感知和推理上可接近，同时速度更优。

### 反证、消融与替代路线

- [Cross-Modal Projection in Multimodal LLMs Doesn't Really Project Visual Attributes to Textual Space](https://arxiv.org/abs/2402.16832)：投影器微调能改善分类，但作者的 post-projection probe 不支持“视觉属性被更充分投到文本空间”的解释。
- [MM1](https://arxiv.org/abs/2403.09611)：原文结论为视觉 token 数和图像分辨率最重要，而其比较的 VL connector 类型影响较小。
- [VILA](https://arxiv.org/abs/2312.07533)：在联合更新 LLM 的设置中，linear connector 优于其比较的 Transformer connector，并强调解冻 LLM 对上下文学习的重要性。
- [SOLO](https://arxiv.org/abs/2407.06438)：取消独立预训练视觉编码器，以线性 patch embedding 接入单 Transformer；代价转为端到端视觉预训练数据、算力和 recipe。
- [Chameleon](https://arxiv.org/abs/2405.09818) 与 [Emu3](https://arxiv.org/abs/2409.18869)：用离散视觉 token 统一自回归建模，取消连续视觉特征到 LLM 的独立 connector，但引入 tokenizer 量化误差和更长序列。
- [Connector-S](https://arxiv.org/abs/2502.11453)：提供连接器操作族分类，可用于区分 mapping、压缩、聚合和融合，而不是只按模型名枚举。

## 如何解释互相冲突的结果

连接器论文之间通常不能直接横比。至少应控制：

- 视觉编码器、输入分辨率和 patch 数；
- 输出视觉 token 数及其进入 LLM 后的总上下文成本；
- LLM 是否冻结、是否联合更新视觉编码器；
- 预训练、指令数据规模与混合比例；
- OCR / 定位等细粒度任务与知识 / 推理等粗粒度任务的占比；
- 延迟、显存、首 token 时间和缓存策略。

因此，MM1 的“connector 类型影响较小”与 Honeybee / TokenPacker 的“连接结构重要”可以同时成立：前者说明在其受控范围内复杂度不是首要因素，后者处理的是局部保真、强压缩或空间聚合的特定瓶颈。

## 证据限制

- 多数结果是作者报告，主干、数据、预算和 benchmark 不同，不能拼成统一排行榜。
- 同名反证论文只覆盖 LLaVA-1.5、四个领域分类集和特定探针；它不能证明 projector 无用，也不能证明信息必然已被删除。
- 离散统一 token 与单主干路线证明“独立复杂 connector 非必要”，不证明“模态接口不存在”。
- 线性 probe、任务准确率、模态打乱敏感性和生成幻觉测量回答不同问题；需组合使用才能判断信息是否保留且被模型利用。
