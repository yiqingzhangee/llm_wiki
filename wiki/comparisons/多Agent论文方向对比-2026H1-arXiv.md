# 多Agent论文方向对比-2026H1-arXiv

> 来源：[[来源-搜索归档-多Agent-arXiv-2026-06-20]]

## 对比口径

本页基于 `raw/search/multi-agent-arxiv/2026-06-20/` 的标题与摘要级信息，对 2026H1 多 Agent 论文方向做初步分层，不做性能结论。

## 方向分层

| 方向 | 代表论文（示例） | 核心关注 | 与工程落地的关系 |
|---|---|---|---|
| 编排与系统结构 | The Orchestration of Multi-Agent Systems；ROMA；MASFactory | 任务分解、调度、协作结构 | 对应工程中的 workflow 设计与状态管理 |
| LLM 协作拓扑 | Graph-of-Agents；Hierarchical LLM-Based Multi-Agent Framework | 层级/图式通信与协同推理 | 对应多角色协作与上下文成本控制 |
| 任务导向应用 | MATA（TableQA）；多机器人规划 | 在垂直任务中验证多 Agent 机制 | 对应业务场景中的可用性与收益评估 |
| 范式综述化整合 | Multi-Agent Systems: From Classical Paradigms... | 统一框架与未来路线 | 对应选型中的术语对齐与能力地图 |

## 初步观察

1. **“协作拓扑”正在成为方法创新主线**，从线性对话迁移到层级或图结构。
2. **论文叙事普遍强调复杂任务表现**，但与生产环境稳定性指标仍存在断层。
3. **应用论文数量上升**，表明多 Agent 研究开始从范式讨论进入任务化验证。

## 冲突与不确定性

- 与 [[主流Agent框架对比-2026-06-20]] 的冲突点在于：论文关注“方法有效性”，框架关注“工程可运营性”。二者评价维度不同，不能直接横比。
- 当前证据主要来自标题/摘要级归档，尚不足以支持“优于单 Agent”这类强命题。

## 后续补充建议

- 为每篇代表论文补齐：任务类型、协作机制、评测数据集、是否开源、复现实验成本。
- 增加“论文方法 - 工程能力映射表”，把学术术语映射到可上线能力（可观测、回滚、治理）。
