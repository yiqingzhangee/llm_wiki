# 跨模态连接器实现方案对照（2026）

> 概念与证据：[[多模态大模型跨模态投影与连接器]]、[[来源-跨模态投影与连接器研究-2026]]。

## 方案总表

| 路线 | 代表实现 | token 行为 | 主要优势 | 主要损失或成本 | 优先场景 |
|---|---|---|---|---|---|
| 逐 token 线性映射 | LLaVA linear | 通常不压缩 | 最小参数、保留 patch 对应、易训练 | token 多，空间交互依赖后续 LLM | 强视觉编码器、短图像上下文、基线 |
| 逐 token MLP | LLaVA-1.5 MLP | 通常不压缩 | 增加非线性分布适配，仍简单 | 加深后收益可能有限 | 默认强基线 |
| 空间池化 + 映射 | AvgPool、DeCo | 固定比例压缩 | 无参数或低参数、保留空间邻域，避免提前语义选择 | 小目标与边界被平均 | 成本敏感、粗粒度理解 |
| Pixel shuffle / CNN 压缩 | C-Abstractor、Honeybee | 可控压缩 | 融合局部上下文、较强空间归纳偏置 | 实现更复杂，压缩率影响细节 | OCR、文档、图表、局部感知 |
| 查询式语义压缩 | BLIP-2 Q-Former | 固定少量查询 | 适合冻结两端、固定预算、可配对齐目标 | 提前语义选择、局部细节和坐标风险 | 小数据适配、冻结 LLM、全局语义 |
| Perceiver Resampler | Flamingo | 固定 latent 数 | 处理可变图像/视频长度，便于多图 | 强压缩下可能遗漏长尾证据 | 多图、视频、长上下文 |
| 局部粗到细注入 | TokenPacker | 高比例压缩后补细节 | 在预算内回注高分辨率局部特征 | 路由和训练复杂，收益依任务 | 高分辨率且预算受限 |
| 多塔空间聚合 | Cambrian-1 SVA | 聚合并压缩 | 保持坐标对应，融合多编码器与尺度 | 多塔计算和部署成本高 | 多视觉专家、OCR/Chart |
| 深层交叉注意力 | Flamingo gated x-attn、跨层视觉重访 | 可复用原视觉特征 | decoder 多层按需访问，缓解入口单点瓶颈 | 改造 LLM、KV 与服务复杂 | 强压缩后仍需细节重访 |
| 连续早期融合 | Fuyu、SOLO | patch 直接入统一主干 | 模块同构、减少独立组件 | 仍有 patch embedding；端到端数据和算力高 | 有完整预训练能力的新架构 |
| 离散 token 统一建模 | Chameleon、Emu3 | 由视觉 tokenizer 决定 | 单一 next-token 目标，理解与生成统一 | 量化误差、长序列、词表与 tokenizer 成为瓶颈 | 大规模原生多模态预训练 |
| 工具 / RAG 外置感知 | OCR、检测器、分割器、结构化检索 | 只输入结果或引用 | 精确、可审计、模块可替换 | 误差级联、工具编排和延迟 | 高风险、精确定位、数值任务 |

## 不同路线把瓶颈放在哪里

| 路线 | 被压缩或受限的位置 |
|---|---|
| Linear / MLP | LLM 上下文与注意力成本 |
| Pooling / pixel shuffle | 空间下采样，风险是局部细节丢失 |
| Q-Former / Resampler | learned queries / latents 的语义带宽 |
| 多塔聚合 / 深层注入 | 训练、显存、缓存与服务复杂度 |
| 连续早期融合 | 端到端视觉学习能力和训练 recipe |
| 离散统一 token | 视觉 tokenizer 的量化质量与序列长度 |
| 工具外置 | 工具召回、结构化接口和编排可靠性 |

“取消 projector”不会取消瓶颈，只会移动瓶颈。

## 选型矩阵

| 约束或任务 | 首选 | 必做对照 | 升级信号 |
|---|---|---|---|
| 单图、粗粒度问答、预算宽松 | 两层 MLP | linear | MLP 与 linear 都无法利用视觉输入 |
| OCR、文档、图表、小目标 | 保留型 MLP 或局部 CNN projector | 同 token 数 pooling、专用 OCR | 局部 probe 和定位持续受限 |
| 视频、多图、上下文紧张 | pooling 或 Resampler | 固定 token 数 MLP / AvgPool | 细节回归集显著下降 |
| 冻结视觉端与 LLM | Q-Former 或小型 connector | linear / MLP | 固定接口容量成为可复现瓶颈 |
| 多视觉编码器 / 多尺度 | SVA 类空间聚合 | 拼接 + linear、参数量匹配聚合 | 简单基线无法对齐坐标或选择来源 |
| 强压缩后仍需精细问答 | coarse-to-fine 或跨层视觉重访 | 单次入口压缩 | 早期丢失证据且后续无法恢复 |
| 从头训练原生多模态模型 | 连续或离散早期融合 | 模块化 encoder + connector | 系统同构收益覆盖预训练成本 |
| 高风险精确感知 | 专用工具 + 结构化证据 | 纯 VLM | 端到端模型不可校准或不可审计 |

## 公平比较协议

1. 固定视觉编码器、LLM、输入分辨率和训练数据。
2. 分别做**同输出 token 数**与**同推理成本**两组比较。
3. 报告可训练参数、训练步数、峰值显存、TTFT 和吞吐。
4. 分开报告粗粒度推理与 OCR、定位、图表、小目标等细粒度任务。
5. 做视觉 token 打乱、遮挡、替换和图文冲突测试，确认模型实际使用视觉证据。
6. 对压缩路线记录信息损失曲线，而不是只选一个 token 数。
7. 对冻结、部分解冻和端到端训练分别比较，不能混为单一 connector 排名。

## 推荐的最小实验阶梯

1. `linear`；
2. 两层 `MLP`；
3. `AvgPool + linear`，扫描 64 / 144 / 256 / 全量 token；
4. 只有细粒度或多塔瓶颈已被复现时，再试局部 CNN、Q-Former、coarse-to-fine 或深层 cross-attention；
5. 统一主干和离散 tokenizer 作为架构级重构单独立项，不作为普通 connector 替换。

停止条件：复杂方案在匹配 token、训练和推理预算后，没有改善目标任务的最差桶，或增益不足以覆盖服务和维护成本。

## 结论

默认基线应简单，但决策依据不是“奥卡姆剃刀”本身，而是可验证的结构需求。粗粒度任务和宽松 token 预算下，linear / MLP 往往足够；强压缩、细粒度空间任务、多视觉塔和视频长上下文，才是复杂连接器最有说服力的适用区间。
