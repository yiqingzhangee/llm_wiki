# 图像对抗防御链路对照（2026-09-02）

> 对照来源：[[来源-图像对抗攻防答辩文档-2026]]、[[来源-对抗图像样本生成原理与实践-2026-06-23]]、[[来源-对抗样本生成与检测调研实验-2026-06-21]]

本页不再只按“攻击方法”列清单，而是把图像对抗防御放回**真实审核链路**里比较：

1. **前处理 / 结构恢复**：让模型先“看见”；
2. **对抗检测触发器**：判断是否需要升阶审核；
3. **语义精审器**：对升阶样本做更重的理解；
4. **最终裁决器**：规则、专模、人工与业务阈值。

核心目的不是找一个“最强单点方法”，而是明确**每种防御该放在链路哪一层、解决哪类失效、代价是什么**。

## 总对照表

| 组件 / 方法 | 放置层级 | 主要解决的失效 | 典型对象 | 优点 | 代价 / 风险 | 更适合的定位 |
|---|---|---|---|---|---|---|
| **SMSP（频域过滤 + 缩放）** | 前处理 | 视觉头看不见 | AI Illusion、隐藏文本、低频结构被高频纹理淹没 | 轻量、可前置、对 Illusion 检出提升明显 | 可能损伤正常细节；参数敏感 | 通用预处理插件 |
| **Blur + HistEq** | 前处理 | 视觉头看不见 | Hateful Illusion、低对比结构 | 实现简单、易灰度上线 | 可能放大噪声或伤正常图 | 低成本兜底预处理 |
| **SegFormer 结构恢复** | 前处理 / 恢复器 | 视觉头看不见 | Illusion 隐藏文字、二值结构被材质化 | 可把“看不见”问题转成结构恢复；适合单独服务化 | 需要训练与部署；泛化依赖数据分布 | 高价值场景专用恢复器 |
| **随机平滑（RS）** | 语义精审前 / 模型增强 | 像素级微扰、表征不稳定 | M-Attack、MPC-Attack 一类迁移攻击 | 对黑盒扰动有稳健性收益 | 多次采样，时延和成本上升 | 离线评测 / 高风险样本精审 |
| **扩散净化（Prune）** | 语义精审前 / 模型增强 | 对抗伪影残留 | 像素级攻击、扩散生成攻击 | 对强攻击压制明显 | 计算重、延迟高，不适合全量前置 | 高风险样本二审 |
| **SFT 粗召 / 违规分类** | 语义精审器 | 看见了但判断错 | 低对比文本、部分风格迁移 / 结构攻击 | 能学习更稳定的语义判定 | 若直接判违规，真实分布误伤高 | 不宜单独主裁决 |
| **对抗检测触发器** | 触发器 | 是否需要升阶审核 | 混合攻击样本、难样本、疑似规避样本 | 最符合业务链路；误伤可控；能省精审成本 | 不能直接给最终违规结论 | 首选前置路由器 |
| **重模型 / 多模态 VLM 二审** | 语义精审器 | 跨区域、跨模态证据整合 | 对抗触发后样本、证据冲突样本 | 语义理解强，能给解释 | 成本高；仍非最终真理 | 升阶精审 |
| **规则 / OCR / 检测专模 / 人工** | 最终裁决器 | 最终业务决定 | 高影响样本、证据冲突、真伪核验 | 可控、可追责、可审计 | 成本高、吞吐受限 | 最终责任层 |

## 按失效模式选防御

### 一类：视觉头根本看不见

典型信号：

- `follow-up hint` 几乎不提升；
- 缩小、模糊、频域过滤后检出率明显上升；
- attention 主要落在背景纹理，而不是隐藏结构。

对应方法优先级：

1. **SMSP / Blur + HistEq**：先用便宜方法恢复低频结构；
2. **SegFormer 结构恢复**：若场景长期存在且收益大，再上专用恢复器；
3. **恢复后再接 OCR / VLM / 规则**：不要直接把“看不见”的原图丢给语义层硬判。

结论：这类问题的第一反应不该是“换更强提示词”或“继续训判别器”，而应是**先修视觉证据，再谈语义理解**。

### 二类：视觉头看见了，但决策层判断错

典型信号：

- `direct prompting` 已能检出大部分证据；
- `follow-up hint` 或更强判别头能显著改善；
- 问题更像语义归因、风险阈值和稳定性不足。

对应方法优先级：

1. **对抗检测触发器**：先识别是否需要升阶处理；
2. **SFT / hard negative 回流**：改善模型对边界样本的稳定判断；
3. **重模型二审 + 规则 / 人工兜底**：把高影响样本交给更重链路。

结论：这类问题不一定需要更重的视觉恢复，而更需要**更好的路由、更多边界样本和更稳的二审机制**。

## 为什么“对抗检测触发器”比“直接判违规”更适合上线

结合答辩文档中的 V1 / V2 对照：

- **V1（直接判违规）**：合成集上提升明显，但真实分布 precision 低，容易误伤；
- **V2（是否需要增强审核）**：precision / recall 更平衡，也更符合实际风控分层。

这说明：

- 在工程上，**触发器**追求的是“别漏掉需要升阶的样本，同时别把正常流量全打爆”；
- 它不需要独立承担最终裁决，因此容错空间更合理；
- 也更容易与现有审核链路兼容，而不是强行替换原主模型。

所以如果目标是上线，不应先问“哪个模型最终分类最高”，而应先问：**哪一层最值得加一个触发器，能把有限算力留给真正难样本？**

## 推荐的最小可用链路

### 方案 A：低成本版

`原图 -> SMSP / Blur+HistEq -> 对抗检测触发器 -> 命中则进 VLM 二审 -> 规则 / 人工最终裁决`

适用：

- 已有成熟审核主链路；
- 先做低成本增强，不大改线上系统；
- 重点目标是拦截 Illusion / 难样本漏检。

### 方案 B：高价值场景版

`原图 -> SegFormer 结构恢复 + 预处理 -> OCR / VLM 联合精审 -> 对抗检测触发器 / 风险分 -> 规则 / 专模 / 人工裁决`

适用：

- 某类隐藏文本 / 伪装攻击长期高发；
- 单次漏检成本高；
- 能接受单独训练和维护恢复器。

### 方案 C：重防御版

`原图 -> 对抗检测触发器 -> 命中后走 RS / 扩散净化 / 重模型二审 -> 高风险样本人工复核`

适用：

- 安全要求高；
- 样本量相对可控；
- 可以接受更高时延与算力消耗。

## 冲突与不确定性

- 各方法的指标来自不同任务口径：Illusion 检出率、对抗检测 precision/recall、迁移攻击 ASR、净化后 ASR，**不能直接横比成统一排行榜**。
- SegFormer、SMSP、Blur+HistEq 更偏“看见证据”的恢复链路；RS、扩散净化更偏“提高鲁棒性”的精审链路，二者解决的问题不同。
- 触发器最适合上线，并不意味着它在学术上“最好”；这里只是说**它最符合真实风控的责任分层**。
- 当前材料以项目复盘和实验总结为主，若后续要定量选型，还需补统一数据集、统一阈值和统一时延预算下的对照实验。
