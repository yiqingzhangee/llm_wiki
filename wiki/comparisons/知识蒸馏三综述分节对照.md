## 3. 关键概念张力（阅读时应对齐）

1. **「在线蒸馏」词语冲突**：Gou 的 *online distillation* 指**师生同步更新**（如 mutual learning）；OPD 的 *on-policy* 强调**训练前缀来自学生策略**，与「是否在线更新教师」正交。两篇语境不同，**不可混为一个定义**。
2. **自蒸馏**：Gou 中多为同网不同深度/时刻；OPD 中常指 **self-play / 特权信息教师变体**；LLM KD 的 Self-Knowledge 侧重**学生自生成+筛选**。三处「自」字需对照原文公式。
3. **特征蒸馏**：Gou 与 LLM KD §3.1.4、OPD white-box logit 级方法有交集，但 LLM 侧还叠加 **RL/偏好** 与 **序列级信用分配**。

## 4. 建议阅读顺序

1. 需要**经典谱系与图示语言**：先 Gou §2–§3，再读 LLM KD §2–§3。  
2. 关心**闭源教师 + 数据合成**：精读 LLM KD §3.1。  
3. 关心**长链推理与 train-test 错配**：在读完 LLM KD §3.2 后读 OPD §2.3–§4。
