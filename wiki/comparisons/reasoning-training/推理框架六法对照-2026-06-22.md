# 推理框架十二法对照（2026-06-22）

> 对照来源：[[来源-LATS-统一推理行动规划-ICML2024]]、[[来源-多智能体辩论提升事实性与推理-ICML2024]]、[[来源-Chain-of-Code-代码模拟混合推理-ICML2024]]、[[来源-Thought-Rollback-自适应回滚推理-ICML2024]]、[[来源-SELF-DISCOVER-自组装推理结构-NeurIPS2024]]、[[来源-DS-Agent-案例推理驱动自动化数据科学-ICML2024]]

| 方法 | 核心结构 | 主要纠错机制 | 典型优势 | 主要代价/风险 |
|---|---|---|---|---|
| LATS | MCTS 搜索树 + 反思 | 环境反馈 + 价值回传 | 交互决策任务表现强 | 搜索成本高，反馈噪声敏感 |
| Multiagent Debate | 多 agent 多轮辩论 | 互评反驳 + 共识收敛 | 提升事实性与稳健性 | 调用成本线性增长，共识不等于真值 |
| Chain of Code | 代码执行 + LM 模拟 | 执行器异常切换、状态跟踪 | 计算/语义混合任务效果好 | 工程接入复杂，依赖代码质量 |
| Thought Rollback | 可回滚推理图 | 错误分析驱动回滚重试 | 抑制错误传播，提升难题求解 | 回滚策略不当会导致冗余探索 |
| SELF-DISCOVER | 任务级结构生成（JSON） | 结构约束 + 模块组合 | 低推理次数下保持增益 | 模块库覆盖不足时效果受限 |
| DS-Agent | CBR 闭环（检索-复用-修订-保留） | 执行反馈与案例迭代 | 自动化数据科学稳定提升 | 案例质量与分布偏移风险 |
| BoT | 思维模板库 + 检索实例化 | 模板复用 + 动态模板更新 | 兼顾准确率与推理成本 | 模板覆盖不足时迁移受限 |
| GLoRe | 全局修正 + 局部修正协同 | ORM/SORM 定位并引导修正 | 提升复杂算术推理纠错率 | 训练与采样链路较重 |
| R3 | 逆课程强化学习 | 从中间状态回退形成近似过程监督 | 稀疏奖励下更稳定探索 | 依赖示例质量与课程参数 |
| AdaProp | 查询相关自适应传播路径 | 语义相关采样 + 连通性保留 | KG 推理中精度/效率平衡更好 | 采样温度与步数较敏感 |
| NRN | 实体相位 + 数值相位双编码 | 数值投影/反向属性投影约束 | 覆盖数值比较与计算型查询 | 建模复杂度与训练成本更高 |
| MR-Ben（评测） | 元推理过程评测框架 | 错误定位 + 错因解释 + 纠偏建议 | 更能识别“会算但不会审”的模型 | 解释评分口径受评审策略影响 |

## 小结

这十二类路径可按“**在线搜索**（LATS/TR）—**并行互审**（Debate）—**结构约束**（SELF-DISCOVER/BoT）—**执行增强**（CoC）—**课程优化**（R3）—**修正协同**（GLoRe）—**图推理扩展**（AdaProp/NRN）—**过程评测闭环**（MR-Ben）”组合使用；在生产环境中，建议按时延预算、错误成本与可解释性要求做分层编排。
