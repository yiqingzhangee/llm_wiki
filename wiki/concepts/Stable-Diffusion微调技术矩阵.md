# Stable Diffusion 微调技术矩阵

> 基于 [[来源-Stable-Diffusion微调技术深度调研-2026-06-23]] 与 [[来源-Stable-Diffusion架构代表性工作与原理深度解析-2026-06-23]] 的系统归纳。本文档聚焦**微调方法的对比与选型**，架构原理见各来源页。

## 方法全景对比

| 方法 | 核心原理 | 修改范围 | 数据需求 | 最低显存 | 关键论文 | 典型用例 |
|------|----------|----------|----------|----------|----------|----------|
| **LoRA** | 低秩分解：Delta W = BA | U-Net / Text Encoder 的 Attention 层（Q, K, V, O） | 15-100 张 | SD1.5: 8GB / SDXL: 12GB | Hu et al., 2021 | 风格迁移、角色一致性、画风学习 |
| **DreamBooth** | 稀有词绑定 + 先验保留损失 | 全 U-Net（或结合 LoRA） | 5-15 张主体 + 200-1000 正则化图 | 16-24GB | Ruiz et al., 2023 | 个人肖像、宠物、产品定制 |
| **Textual Inversion** | 嵌入空间搜索新概念向量，不修改权重 | 仅 Text Encoder 词嵌入 | 3-10 张 | 8GB | Gal et al., 2022 | 轻量概念注入、纹理学习 |
| **ControlNet** | 可训练 Encoder 副本 + 零卷积连接 | 独立训练的 Encoder 副本支路 | 数千-数万张（条件-图像对） | 12-24GB | Zhang et al., 2023 | 姿态控制、深度引导、边缘生成 |
| **IP-Adapter** | 解耦交叉注意力：图像/文本独立 K-V 投影 | 新增图像交叉注意力层的投影矩阵 | 大规模图文对 | 12-16GB | Ye et al., 2023 | 图像风格参考、内容迁移 |
| **DoRA** | 权重分解为幅度+方向，分别优化 | Attention 层（方向用 LoRA，幅度独立） | 同 LoRA | 同 LoRA | Liu et al., 2024 | 高保真风格学习、复杂概念 |
| **OFT** | 学习正交变换矩阵，保持超球面能量守恒 | Attention 层（正交约束） | 同 LoRA | 同 LoRA | Qiu et al., 2023 | 需严格保留原模型分布的场景 |
| **LyCORIS 系列** | LoCon/LoHa/LoKr：扩展到卷积层、Hadamard/Kronecker 积分解 | Attention + Conv 层 | 同 LoRA | 8-16GB | KohakuBlueleaf, 2023 | 高表达力风格、复杂纹理 |
| **全微调** | 更新模型所有参数 | 全 U-Net（所有层） | 数万张以上 | 24GB+ | — | 医学影像、遥感、垂直领域大规模迁移 |

## 训练框架选型

| 框架 | 核心定位 | 最低显存 | 目标用户 |
|------|----------|----------|----------|
| **Diffusers** | 工业级标准库，PEFT 集成，模块化 API | 8-12GB | 开发者/研究者 |
| **Kohya_ss** | 社区标准，多分辨率分桶，LyCORIS 原生支持 | 8GB | 进阶创作者 |
| **SimpleTuner** | 多 GPU + DeepSpeed，Flux/SD3 优先 | 10GB（量化） | 高性能需求 |
| **OneTrainer** | 全能 GUI，Tensorboard 集成，自动备份 | 12GB | 进阶用户 |

## 关键超参数速查

### 学习率

| 场景 | 推荐值 |
|------|--------|
| LoRA (SD 1.5) | 1e-4 至 5e-5 |
| LoRA (SDXL) | 约 1e-5 |
| Text Encoder | 5e-6 或更低 |

### Rank 选择

| 场景复杂度 | 推荐 Rank | 说明 |
|------------|-----------|------|
| 简单概念/物体 | 8-16 | 足以捕捉单一概念的视觉特征 |
| 复杂面部/多姿态 | 32 | 需要更多参数容量表达面部细节 |
| 复杂艺术风格 | 64-128 | 画风包含大量纹理和色彩模式 |

**Alpha 设置**：社区共识为 Alpha = Rank/2 或 Alpha = Rank。实际影响力遵循 alpha/r 缩放。

### 高级训练技巧

- **Min-SNR Weighting**：snr_gamma = 5.0，加速收敛并改善对比度
- **Noise Offset**：0.1，改善高动态范围（极黑/极亮区域）
- **LoRA 合并**：ZipLoRA (2024) 可实现主体 LoRA + 风格 LoRA 的完美合并

## 常见失败模式

| 失败模式 | 症状 | 解决方案 |
|----------|------|----------|
| **过拟合** | 生成图与训练集几乎相同，无法改变服装/姿势 | 降低 LR、减少 Epochs、增加正则化图、调低 LoRA 权重 |
| **灾难性遗忘** | 训练角色后无法画其他主题 | 降低 Text Encoder 训练步数、增加正则化图像 |
| **模式崩塌** | 所有生成图构图和光影千篇一律 | 提高数据多样性、降低 LR、检查 Loss 曲线 |
| **色彩溢出** | 目标概念颜色泄漏到不相关区域 | 在标注中明确区分颜色属性、增加背景多样性 |

## 选型决策路径

```
需要精确空间控制？
├── 是 → ControlNet（姿态/深度/边缘）
└── 否 → 需要图像作为提示词？
    ├── 是 → IP-Adapter
    └── 否 → 训练数据量？
        ├── 3-10 张 → Textual Inversion（最轻量）
        ├── 5-15 张 → DreamBooth（需要主体一致性）
        ├── 15-100 张 → LoRA（最佳性价比）
        └── 数万张+ → 全微调（垂直领域迁移）
```
