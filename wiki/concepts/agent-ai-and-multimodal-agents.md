# Agent AI 与多模态智能体

与已摄入综述 [paper-agent-ai-survey-2401-03568.md](../sources/paper-agent-ai-survey-2401-03568.md) 及 2026-06-23 新增翻译来源对齐的综合表述。

## 定义（据来源）

- **Agent AI（智能体 AI）**：能感知**多模态**、**环境落地**的输入（视觉、语言、音频、场景上下文等），并产出**行动**（含具身行动），而非仅生成文本补全的系统。
- **多模态 Agent AI（MAA）**：在上述设定下，由**多模态感知上的策略**驱动行为的一类智能体；综述覆盖游戏/VR/AR、机器人、医疗及一般跨模态场景。
- **LLM-Brained GUI Agent**：Agent AI 在数字界面领域的具体实例化——在 GUI 环境中运行，以 LLM/VLM 为核心推理引擎，通过截图感知和点击/输入/手势等操作执行多步任务的智能体。

## 动机

- **整体式 AI**：重新贯通感知、推理、记忆与行动（相对分科过细的研究）。
- **落地以缓解幻觉**：在环境中落地有望减轻**幻觉**与**物理/情境上不合理**的模型输出。
- **基础模型作构件**：LLM 与 VLM 提供语言/视觉理解与规划先验；智能体补充**交互闭环**、**工具**与**具身**。
- **跨现实部署**：Agent AI 的训练可使用跨现实数据（物理 + 虚拟），训练完成后可同时部署于物理和虚拟环境，实现“现实无关”的泛化。

## 方法（高度概括）

论文目录涉及：强化学习、模仿学习、上下文学习、智能体栈中的优化、模块化智能体基础设施，以及面向行动的 **智能体基础模型**（预训练/微调）。从认知架构角度看，CoALA 将这些方法统一为四类动作（推理/检索/学习/落地）的结构化决策循环。

## 理论底座

- **CoALA（认知架构）**：将 LLM 视为概率产生式系统，用记忆（工作/情景/语义/程序性）+ 动作空间（内部推理检索学习 + 外部落地）+ 决策循环（规划-执行）组织语言代理。为理解 Agent AI 的建筑学提供了最系统的理论框架。
- **统一四模块框架（Renmin）**：画像-记忆-规划-行动的四模块分解，为 Agent AI 的工程实现提供了可操作的组件蓝图。

## 与本 wiki 中代码来源的关系

- **LangGraph**（[实体](../entities/langgraph.md)、[来源](../sources/repo-langgraph.md)）：面向有状态、可持久、可含人在回路的 **工作流** 的**图编排**实现层；位于「Agent AI」研究范畴之下的工程层。
- **Claude Code 相关栈**（[claude-code-best-practice](../sources/repo-claude-code-best-practice.md)、[gstack](../sources/repo-gstack.md)）：面向开发者的 **命令/技能/子智能体** 等工具链，不是机器人具身，但在**规划、工具、记忆与人机协同**上与智能体主题相通。
- **GUI Agent 框架**（UFO、AppAgent、SeeAct 等）：Agent AI 在桌面/移动/Web 界面的具体落地，是连接多模态感知（截图理解）与动作执行（点击/输入）的工程范式。
