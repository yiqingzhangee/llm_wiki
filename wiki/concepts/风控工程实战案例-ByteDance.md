## 背景与时间线

- **国际化电商营销风控**（2021.11 - 2025.05）：美英、欧盟、东南亚、中东等十多个海外市场
- **TikTok 短视频社区内容风控**（2025.05 至今）：AI Agent 工程化 + 违规内容专项治理 + 行为感知优化

## 核心工程架构

### 电商风控：三层防御 + 200+ 模型体系

事前预警 ──→ 事中拦截 ──→ 事后追溯

    ▼              ▼              ▼

**关键指标**：
- 风险识别首次上线扩招 10 倍，常态化月扩招 30%

**大模型辅助技术栈**：
- 40B 大模型 + 动静结合提示词 → 风险地址清洗（风险订单占比提升 50%+）

- 半监督团伙检索 + motif 图模型 → 精准打击黑产

### 色情闪帧专项治理架构

```
视频输入
  → 粗筛（低频抽帧，过滤正常视频）
    → 精检（毫秒级密集抽帧，动态密度调控）
      → 多帧特征融合（区分转场 vs 恶意闪帧）
        → Dinvo2 小样本模型（快速适配变种）
          → 图片黑库交叉比对
            → 临界置信度二次复检
              → 人审 → 处罚 → 黑库更新
```

**关键指标**：
- 用户举报下降 34%
- 日均处罚 6000+ 账号
- 突发闪帧风险 48 小时内全量止损

### 相似帧去重多级联动

| 方法 | 定位 | 速度 | 适用场景 |
|------|------|------|----------|
| aHash/dHash | 粗筛 | 极快 | 单视频内冗余帧清理 |
| pHash | 主力匹配 | 快 | 黑库检索、跨视频溯源（抗缩放/裁剪/转码） |
| ORB 特征点 | 对抗精判 | 中 | 翻转/遮挡/异形裁剪 |
| 深度语义 Embedding | 语义去重 | 慢 | 重度二创、换背景（结合向量数据库） |

**pHash 原理**：DCT 变换 → 保留左上角 8x8 低频系数 → 均值二值化 → 64 位哈希 → 汉明距离判定（≤5 高度相似、6-10 精判、>10 不相似）

**重要踩坑**：全屏纯色/全黑/全白等低熵画面极易哈希碰撞，需前置图像熵值过滤。

### 团伙挖掘：从支付风控到内容风控的迁移

四层全量改造，非直接照搬：

1. **图关系重构**：资金流 → 设备/IP/行为/内容哈希/社交多维异构图
2. **特征体系改造**：剔除金融特征 → 短视频时序行为 + 多媒体内容 + 群体统计
3. **算法策略适配**：重新定义长/短期周期（临时突击 vs 长期养号），局部社区搜索保持秒级挖掘
4. **业务规则适配**：团伙置信度打分（关联强度 + 行为相似度 + 内容同源率），分层处置（主号/马甲号差异打击）

### 样本回流全流程

```
数据采集（4 源：漏判/误判/举报/专项）
  → 分层降噪（帧哈希去重 + 置信度筛选 + 预分类）
    → 数据标准化（抽帧/OCR/特征挂载）
      → 分池分发（应急池/漏判池/误判池/疑难池）
        → 多级标注质检（一审 + 二审复核）
          → 分区入库（训练/规则/评测/复盘）
```

**0day 应急通道**：跳过部分常规过滤逻辑，小样本模型几十条样本即可增量迭代，最快数小时完成闭环。

## 关键工程决策

### pydantic-ai vs LangChain

选择 pydantic-ai 的理由：
1. Agent 以短流程、少轮次工具调用为主，pydantic-ai 轻量化启动开销远低于 LangChain
2. 原生 Pydantic 强类型校验，严格约束 LLM 输入输出格式，避免线上服务报错
3. 二次封装简单，适合风控策略高频迭代
4. LangChain 组件冗余，更适合复杂长对话场景，不适合高并发线上链路

### Strictest-Win 并行决策逻辑

多 Policy 子 Agent 并行执行，任意一个判定违规即最终判定为风险，只有所有 Agent 全部判定正常才放行。不做投票折中，从源头降低漏判率。

### Durable Queue 心跳机制

任务节点从队列领任务 → 持有租约 → 持续上报心跳 → 节点宕机/心跳中断 → 租约自动过期 → 任务重回队列 → 其他节点重新领取执行。保障大批量长任务不丢失、不卡死。

### 多帧融合方案选择

线上实时链路优先使用相邻帧特征拼接 + 2D 卷积（推理快、算力小），仅离线精检场景使用 3D 卷积提取完整时序特征。

### 高密度抽帧成本优化

1. 动态抽帧（仅高风险视频/突变片段密集采样）
2. 图像预处理统一压缩分辨率
3. 推理优化（模型量化 + 批次合并 + 异步流水线）
4. 数据清理（临时抽帧不持久化，分析完成即清理）
