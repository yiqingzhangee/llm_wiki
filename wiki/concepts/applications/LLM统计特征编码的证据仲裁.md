## 核心命题

统计特征进入 LLM 不等于系统已经获得可靠裁决能力。必须将三个问题分开：

1. **保真编码**：数值、单位、缺失与时间结构是否仍可被模型或工具使用；
2. **证据仲裁**：多个统计值、文本摘要和工具结果能否比较、合并或应保留冲突；
3. **行动授权**：系统是否可据此触发阈值、写操作或业务处置。

LLM 可以提取候选、解释差异和建议下一步，但流畅解释、模型置信度或候选投票都不能替代数据版本检查、确定性复算和业务规则。

## 最小统计特征证据包

每个统计值应与其语义和可用性一同编码，而不是只传递裸数字。

| 字段 | 必要作用 | 缺失时的风险 |
|---|---|---|
| 数值与单位 | 说明测量量纲和有效位数 | 把不同单位或尺度直接比较 |
| 分母/聚合口径 | 说明比例、均值、分位数的对象范围 | 产生分母变化或聚合层级错觉 |
| 有效时间窗 | 标记统计覆盖的开始、结束与刷新时间 | 用旧窗口回答当前问题 |
| `event_time` / `available_at` / `prediction_cutoff` | 区分发生、可得和决策时点 | 未来信息泄漏或状态错位 |
| 实体键与来源版本 | 追溯对象、表版本和派生链 | 把不同实体或同源转述当作独立证据 |
| 缺失掩码与覆盖信息 | 表示未观测、延迟和采样稀疏性 | 把缺失默认为零或完整观测 |
| 派生规则与工具参数 | 支持重算和审计 | 无法判断数字是否可复现 |

`confidence` 不能混同于证据等级：前者可以表示抽取或模型不确定性，后者还要考虑来源可信度、计算可复现性和数据覆盖程度。日粒度重复记录也不等于统计独立样本。

## 编码路径与结构保真门禁

| 路径 | 需要保留的结构 | 最小验证 | 退出条件 |
|---|---|---|---|
| 确定性文本化 | 字段名、数值、单位、时间窗、缺失标记 | 模板变体、数值/单位置换、强基线 | 模板敏感或数值语义丢失 |
| 软 token / 连续编码 | 数值尺度、missing mask、更新时间与时间间隔 | 去掉 mask、随机置换数值、同预算晚融合 | 无稳定增益或可审计性退化 |
| 独立编码器 + 投影器 | 原生统计窗口、跨列关系和来源元数据 | 原生模型、文本化、简单投影对照 | 连接器忽略结构或服务 SLO 不合格 |

完整选型与成本边界见 [[异构数据接入大模型的四档方案对比-2026]]。所有路径均需保持 [[Qwen异构特征接入与事件序列建模]] 中的先切分后预处理、时间外验证和实体隔离要求。

## 冲突分类与仲裁状态

系统不应只返回单一数字或结论，而应返回可审计的证据状态。

| 冲突类型 | 典型原因 | 推荐状态与下一步 |
|---|---|---|
| 可复算且一致 | 数据与工具在同一口径下相符 | 输出结论和复算记录 |
| 可比较但范围不同 | 时间窗、实体范围或采样频率不同 | 并列输出适用范围，不自动合并 |
| 冲突待复算 | 文本、统计和工具结果不一致 | 触发受控查询或回放 |
| 定义/单位不兼容 | 分母、币种、口径、裁剪规则不同 | 拒绝比较或先做确定性换算 |
| 来源非独立/版本不明 | 同源转述、派生链缺失 | 降低独立证据权重并补齐溯源 |
| 证据不足 | 缺失、延迟、覆盖不足 | 路由补证或人工复核 |
| 不可自动合并 | 高影响决策或冲突无法消除 | 保留分歧，禁止自动处置 |

建议性输出字段为：候选值/结论、来源、适用窗口、冲突类型、证据等级、复算状态、置信/覆盖说明与下一步动作。可复算的一手工具结果可优先于生成文本；同等级冲突必须保留分歧，不能由模型置信度覆盖。

## 论文锚点：文本、数值与工具冲突的受控基准

[[来源-文本与数值冲突下的LLM证据仲裁-2026]] 提供了一手预印本的受控实验锚点：同一潜在风险轨迹被表达为数值序列、文本摘要与外部预测，并分别操纵模态、时间新近性、显式可靠性和工具溯源。其图 4 的作者报告表明，单源条件下的高准确率不能保证冲突下的稳健仲裁；证据顺序和后置的错误工具预测可显著改变决策。

这支持把 `evidence_modality`、观察时间、来源可靠性声明、派生链和 `tool_execution_id` 纳入最小证据包，并把“错误工具预测”纳入压力测试。它不证明本页状态机已完备：该研究是合成、模板化的二元任务，时间线索与提示位置也尚未完全分离。

## 裁决与行动的责任边界

[[来源-社区风控欺诈Agent判定数据-2026]] 提供了一个字段级治理抽象：裁决状态、业务风险标签、证据文本、置信度和辅助标签应分开保存。`ambiguous` 是路由到补证或人工复核的状态，不应被强制二元化。

因此，LLM 的职责应限于结构化解释、候选归因和证据整理；最终阈值、权限和处置由独立校准器、规则、工具与人工复核控制。对于高影响场景，必须保留输入版本、工具参数、复算结果和人工覆盖记录。

## 最小压力测试与退出条件

- 数值置换、单位扰动、分母/聚合口径替换；
- 缺失掩码移除、时间错位、旧状态与新事件混合；
- 实体键错配、同源转述伪装成多源、来源版本回退；
- 文本解释与工具复算冲突、后置错误工具预测、生成参数与实际执行参数不一致；
- 时间外滚动切分、实体隔离、冲突桶、校准、最差切片、p95/p99、成本与回退率。

若复杂编码未稳定超过确定性统计、专用模型或人工复核队列，或冲突桶、校准、可审计性与服务 SLO 退化，则回退到更简单、可复算的路径。

## 与状态—事件混合的接口

统计条件为事件生成或回放提供状态约束，但生成输出若形成统计结论，仍必须携带窗口、版本和复算状态。状态/事件如何分通道编码、生成与回放见 [[状态—事件混合生成与M3]]；两页共享证据包和时间可用性契约，但本页是唯一的统计裁决规范入口。

## 不确定性

- 现有来源支持渐进接入、结构保真和确定性边界，不支持任何单一软 token、投影器或主干模型的通用优越性。
- 内部风控材料仅支持字段与工作流抽象，不能外推风险比例、模型效果或跨业务结论。
- 仲裁框架需要在目标任务中以因果消融、离线回放、校准和线上 SLO 进行验收；没有这些验证时，它只是设计建议。
