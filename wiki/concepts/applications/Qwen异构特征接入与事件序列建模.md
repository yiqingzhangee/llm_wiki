# Qwen 异构特征接入与事件序列建模

> 关联来源：[[来源-Qwen事件序列分类最小PoC-2026]]、[[来源-Qwen事件序列与统计特征融合方案-2026]]、[[来源-Qwen3-VL统计特征编码器调研-2026]]、[[来源-Qwen3-VL事件序列编码器调研-2026]]、[[来源-RecFormer-P5-M6Rec推荐数据文本化-2026]]。

## 核心命题

事件序列、统计特征与文本可以接入 Qwen，但“能进入主干”不等于“应使用主干”。合理路线应先证明数据中的顺序、数值或语义提供不可替代增益，再以最小改造逐层增加表示能力；任何阶段都要保留 GBDT、GRU、线性模型与晚融合等强基线。

## 数据契约先于模型

- 记录每条输入的 `event_time`、`available_at` 与 `prediction_cutoff`；仅使用预测时点可获得的字段。
- 先时间切分与实体/强相关群组隔离，再构建序列窗口、插补、标准化、事件字典和聚合特征。
- 数值同时携带标准化值、单位/裁剪规则、缺失掩码和距最近观测时间；缺失不是零。
- 训练、回放与线上复用同一特征函数、版本和可见性规则；泄漏审计未通过时所有模型结果均无效。
- 状态快照与事件历史应分通道保留：状态需带快照时间和版本，事件需带发生/可用时间与实体键；不应仅依靠同一段自然语言模板消解二者差异。关于状态—事件混合、统计冲突与行动控制面的系统门禁见 [[LLM表征与对齐总统简报-2026]]。

## 分阶段接入路线

| 阶段 | 路线 | 解决的问题 | 必须击败的对照 |
|---|---|---|---|
| P0 | 规则、LR、LightGBM、GRU、BERT4Rec 与文本化 Qwen | 信息与顺序是否有增量 | 无特征、事件单路、统计单路、双路文本 |
| P1 | 确定性模板 + LoRA/QLoRA | 语言语义是否提供增量 | 未微调 Qwen、专用基线、模板变体 |
| P2 | 数值 MLP/编码器 → 少量 soft token + 零门控，可叠加 LoRA | 连续数值、缺失和时间结构是否需专用通道 | 文本 LoRA、冻结适配器、同容量晚融合 |
| P3 | 少数层交叉注意力或有限主干改造 | 是否存在可复现的动态交互容量瓶颈 | 输入软 token 与参数量匹配侧路 |

`adapter/projector` 负责把外部连续特征接入模型；`LoRA` 负责低秩更新主干对输入的利用方式。它们的职责不同，可联合训练而不可互相替代。

## Qwen3-VL-4B 的连续向量与可选 token 接口

> 可视化：打开 [统计特征与事件序列编码器算法示意图](../../../encoder-algorithm-diagrams/encoder-algorithm-diagrams.html)，查看两条最小工程链路、连续向量输出、可选 token projector 与联合接入方式。

统计与事件编码器首先输出独立、可复用的连续向量，而不是直接绑定 Qwen token：

```text
统计字段 → 字段语义/ID/取值加法融合 → 两层 MLP → stat_vector [B,256]
事件序列 → 描述/ID/时间/payload 加法融合 → 单层 GRU → sequence_vector [B,128]
```

这两个向量可以直接接专用分类头或 late fusion。只有需要 Qwen3-VL 联合建模时，才分别通过独立 zero-gated projector 生成一个 `[B,1,2560]` soft token。完整选型见 [[Qwen3-VL统计特征编码器选型-2026]] 与 [[Qwen3-VL事件序列编码器选型-2026]]。

最低成本统计方案采用字段级直接加法和固定顺序拼接，不使用 FiLM 或查询压缩。最低成本事件方案用单层 GRU 的最后有效 hidden state，不使用 attention pooling、Transformer、Mamba 或 TPP。固定英文描述均由冻结文本编码器离线计算并版本化缓存；可训练字段/事件 ID embedding 保留任务特定校正能力。

当事件可以稳定映射为离散 ID 且目标是预测被遮住/下一事件时，[[BERT4Rec数据处理与输入张量]] 是比通用 Qwen 更直接的双向 Transformer 基线。它以 `[B,L]` ID 序列、padding mask 与 Cloze 标签建模，不直接接收文本、时间戳或 payload；加入这些通道后应与原始 ID-only 基线分开消融。

首版为统计和事件各保留一个独立占位 token，便于分别消融。官方配置中语言主干 `hidden_size=2560`，因此只有可选 projector 的输出需要对齐 2560；编码器内部维度不需要对齐视觉塔或语言主干。

推荐由 wrapper 在 embedding 层替换两个独立占位。图像/视频与自定义 token 并存时，应先用原始 `input_ids`、多模态 token 类型和视觉网格计算 M-RoPE 位置，再替换 embedding 并显式传入 `position_ids`。不要把连续向量伪装成图片。

当前没有 Qwen3-VL 直接 benchmark 支持某一方案普适最优。标准 Transformers `forward()` 可由 wrapper 接入，但 `generate()`、vLLM 和 SGLang 的自定义 embedding 链路必须单独验证。

已发布模型提供了两种可借鉴的上游结构。LUMOS 用独立 MLP 编码行为、事件上下文和静态特征，在每个时间点融合后进入 Transformer；FOUNDv2 则把文本、行为和表格属性统一量化为用户 token。前者更接近本页的连续 `sequence_vector + stat_vector` 路线，后者适合需要长期压缩与跨任务复用的场景。完整对照见 [[多模态行为序列与表格编码器对比-2026]]。

## 读出、损失与确定性边界

固定闭集分类优先使用 mask 感知池化或最后一个有效 token 的隐藏状态接分类头，输出可校准 logits；只有开放标签、解释或生成任务才增加自回归出口。统计计算、阈值判断和高影响动作保留给确定性代码、校准器、规则和策略引擎；多源统计冲突时应先输出候选证据、适用窗口与复算状态，而不是让自回归文本直接承担最终数值仲裁。

## 最小消融集

- 历史长度 L=1/2/4/8、顺序打乱、事件删除/交换与未知 code；
- 统计单路、随机置换、去掉 missing mask、去掉时间间隔；
- 文本拼接、软 token、零门控、交叉注意力的同预算比较；
- 时间外滚动折、实体隔离及二者交集；
- AUC/PR-AUC 之外的 Brier、ECE、最差桶、p95/p99、显存、吞吐与成本。

## 停止与回退

若 Qwen 没有稳定超过强基线，连续通道没有超过文本化，或最差桶、校准、漂移、服务 SLO 不可接受，则停止结构升级，回退到 GBDT/GRU/规则，并将 Qwen 限定在异步语义解释或离线特征生产。短序列并不天然需要更复杂的注意力模型。

## 不确定性

`inputs_embeds` 支持和视觉模型的编码器—投影器—语言主干结构只构成接口旁证；Qwen 的具体版本、训练栈和推理引擎对 soft-token 批处理与缓存的支持均需目标环境复测。本页讨论模型和工作流，不将其归为 Agent 架构。
