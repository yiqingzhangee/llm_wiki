## 核心结论

纯自监督学习不定义风险。它学习的是事件、时间和字段的生成结构；风险边界来自标签、规则、监管口径与代价函数。预训练目标的职责是尽量保留下游判断所需的信息，并降低少量标注的提取难度，而不是让模型从无标签分布中自动产生“好坏”概念。

风控行为序列没有一个通用的最优自监督目标。目标应由表示的使用方式决定：

- **在线逐事件判断**：以因果的下一事件类型、字段和时间间隔预测为主，保证每个时点只读取历史。
- **离线完整窗口表征**：以字段或事件掩码恢复为主，再用子序列对比补充主体级稳定属性。
- **不规则时间序列**：除事件内容外，还要建模等待时间和“没有事件发生”的区间。
- **需要跨任务复用的序列向量**：局部恢复与全局对比可以联合，但必须分别验收，不能只看总损失。

直接风控与金融交易论文、通用事件流研究和推荐序列文献共同支持三类基础目标：掩码恢复、自回归下一事件预测和序列对比。它们分别偏向局部内容、动态状态和全局主体属性。工程上更重要的问题不是目标数量，而是预测时点、增强语义、负样本关系和高频行为捷径是否定义正确。

## 目标族

| 目标族 | 典型监督 | 主要学习内容 | 适用位置 | 风控中的主要风险 |
|---|---|---|---|---|
| 字段级掩码恢复 | 恢复事件类型、对象、渠道、金额分桶等 | 事件内部结构和局部上下文 | 多字段交易、离线完整窗口 | 高频字段主导，未遮蔽重复值泄漏答案 |
| 事件级掩码恢复 | 恢复完整事件或事件潜向量 | 行为转移和上下文依赖 | 离线编码器、双向 Transformer | 稀有关键事件被遮蔽后语义改变 |
| 下一事件生成 | 预测下一事件类型或各字段 | 因果动态状态 | 在线风控、前缀编码 | 模型退化为高频正常行为预测器 |
| 时间目标 | 预测下一时间差、累计时间或事件强度 | 节奏、突发性和沉默期 | 不规则时间事件流 | 时间变换和删失边界不一致 |
| 子序列对比 | 同主体不同窗口为正，不同主体为负 | 稳定主体属性和全局模式 | 多任务复用、检索和聚类 | 相邻状态被错当正样本，同风险状态被错当负样本 |
| 模式感知对比 | 保留重复模式或局部变化的增强视图 | 重复型与零星型行为模式 | 已知业务形态较清楚的领域 | 增强先验错误会固化错误不变性 |
| 意图或原型对比 | 序列靠近聚类得到的状态原型 | 潜在阶段和群体结构 | 阶段发现、领域引导或弱监督迁移 | 原型被高频正常群体占据 |
| 跨粒度关联 | 事件、属性、子序列和整序列间匹配 | 局部与全局的一致性 | 多粒度用户表征 | 代理任务过多，优化目标互相干扰 |

## 三类基础目标

### 掩码恢复

设行为序列为 `x = [e_1, ..., e_L]`，每个事件含多个字段。对位置集合 `M` 做遮蔽后，可按字段分别恢复：

```text
L_mask = Σ_(t∈M) Σ_k CE(p(x_(t,k) | x_masked), x_(t,k))
```

多字段事件不宜直接压成一个巨大组合类别。字段级头更容易表达异构词表，也便于检查某个高频字段是否压过其他目标。连续字段可以分桶分类、回归或在潜空间恢复，但三者的误差含义不同，必须单独定义。

掩码任务适合离线完整窗口，因为双向上下文会读取目标位置两侧的信息。若表示最终用于在线时点判断，应另做严格因果版本，不能把双向掩码模型的效果直接当作在线证据。

### 下一事件与时间预测

因果目标只允许输入历史前缀：

```text
input  = [e_1, ..., e_t]
target = e_(t+1), Δt_(t+1)

L_next = L_type + Σ_k λ_k L_field_k + λ_time L_time
```

事件类型、事件字段和时间间隔提供不同信号。只预测事件 ID 容易忽略金额、对象和渠道变化；只预测时间则无法区分不同动作。对不规则事件流，还可以把“某段时间没有事件”作为显式训练信号。

这类目标与在线风控的时间语义最接近，但也最容易被高频正常行为支配。应同时报告按事件频率分桶的损失、稀有事件召回和时间残差，而不是只看总体交叉熵。

### 序列与子序列对比

从同一主体构造两个语义等价视图，得到表示 `z_a`、`z_b`：

```text
L_con = -log exp(sim(z_a, z_b) / τ)
              --------------------------------
              Σ_j exp(sim(z_a, z_j) / τ)
```

对比目标擅长约束序列级表示，但“同主体”不总等于“同状态”。跨越状态转折或风险发生时点的两个窗口可能不应拉近。不同主体也可能处于相同风险阶段，直接作为负样本会制造假负样本。

同一主体的其他时段也不应默认作为负样本。没有状态变化证据时，这种做法会把个体稳定属性推远；只有变化点、策略或成熟标签表明两段状态不同，才适合作为 hard negative。若该证据来自风险定义层，训练已属于弱监督而非纯自监督。

风控增强应先定义不变量，再决定操作：

| 操作 | 默认态度 | 需要验证的问题 |
|---|---|---|
| dropout 视图 | 相对保守 | 模型噪声是否足以形成有效正样本 |
| 轻度字段遮蔽 | 可用 | 是否保留关键字段和最小上下文 |
| 子窗口采样 | 条件可用 | 两个窗口是否位于同一预测时点和状态 |
| 事件删除 | 谨慎 | 被删事件是否是稀有但决定性的信号 |
| 顺序重排 | 通常不建议 | 风险语义是否依赖方向和先后关系 |
| 事件替换或插入 | 需要领域约束 | 替换后是否仍是可实现、语义等价的轨迹 |

## 联合目标怎么设计

一种常见组合是：

```text
L = λ_mask L_mask + λ_next L_next + λ_time L_time + λ_con L_con
```

这只是记账形式，不代表各项能够自然协同。掩码恢复偏局部当前状态，对比目标偏全局主体属性，下一事件目标偏动态演化。简单等权相加可能造成梯度冲突，或让最容易的高频任务占据主干容量。

联合训练至少应记录：

- 每个分项损失及其梯度范数；
- 按事件频率、序列长度和来源分桶的指标；
- 正负样本相似度和表示方差；
- 有效掩码数、稀有关键事件覆盖率；
- 下一事件类型、字段和时间目标的独立误差；
- 冻结编码器后的时间外线性探针。

如果一个分支长期不学习，先检查样本合同和目标冲突，再考虑动态权重、交替训练或分阶段预训练。增加损失项本身不是改进。

## 纯自监督、领域先验与弱监督

- 掩码恢复、因果下一事件预测和不依赖风险标签的合法视图一致性属于纯自监督。
- 保护关键事件、提高特定事件遮蔽概率或禁止破坏方向的增强属于领域引导自监督。
- 用策略命中、人工复核、成熟坏样本构造 hard negative、可疑原型或风险变化点禁配属于弱监督或半监督。

这些外部信号通常比继续堆叠通用代理任务更直接，但实验必须标明信号来源。遮蔽倍率、损失权重和采样比例应由时间外消融决定，不应写成跨业务通用常数。

模型输出的负对数似然或能量值应称为行为新颖度或模型失配分数，而不是“无标签风险分”。它只有在成熟标签、合法异常切片和规则变更切片上完成校准后，才可能成为风险特征。

变化点检测同样需要明确统计对象。嵌入向量不是概率分布，不能直接计算 KL 散度；可在相邻表示窗口上使用 MMD、能量距离或 CUSUM，或先拟合密度再计算散度。

## 内部与外部方案对照

| 证据 | 采用的目标设计 | 可迁移结论 | 证据边界 |
|---|---|---|---|
| 已脱敏内部实践 | InfoNCE 类序列对比 + 掩码恢复 | 局部恢复与全局一致性应分项验收 | 未公开代码与完整损失合同 |
| TabBERT | 多字段交易的字段掩码恢复 | 多字段事件适合字段级恢复 | 欺诈实验使用合成交易数据 |
| BERT4ETH | 掩码地址预测 + 频率感知负采样 | 重复行为会泄漏答案，幂律频率会主导目标 | 链上地址语义不同于一般账户行为 |
| UB-PTM | 动作、意图、整序列多粒度代理任务 | 风控预训练不宜只监督单事件 | 公开页未披露全部损失细节 |
| SAGE | 序列变异恢复 + 序列重组 | 可以围绕鲁棒性和一致性设计领域任务 | 具体扰动需按本地事件语义重审 |
| CLeAR | 序列对比、下一行为匹配、子序列匹配 | 动态预测与全局表征可联合 | 当前核验到公开摘要与任务描述 |
| MaP | 掩码恢复 + 行为一致性与局部破坏增强 | 增强应针对重复型和零星型模式 | 单一社交平台恶意用户场景 |
| CoLES / CMLM | 子序列对比 + 潜空间掩码事件恢复 | 全局主体属性与局部状态互补 | 简单相加不一定产生协同 |
| SOHET | 下一类型、下一时间差、下一行潜表示对比 | 在线异构事件应联合内容与时间 | 2026 年预印本，仍需独立复现 |

推荐系统中的 BERT4Rec、S3-Rec、CL4SRec、CoSeRec、DuoRec 和 ICLRec 提供了成熟的目标结构，但不是风控收益的直接证据。特别是随机裁剪、重排和“相同下一 item 即同类”的假设，迁移前必须重新验证。

## 按场景选型

### 在线因果编码

建议首版使用：

```text
下一事件类型 + 关键字段预测 + 时间间隔回归
```

全部特征相对当前时点构造，主干使用因果掩码。若需要固定序列向量，可在各前缀状态上池化或读取最后有效状态。后续再增加受约束的对比项，验证它是否改善时间外风险探针，而不是只改善相似度指标。

### 前缀长度与监督位置

长度为 256 的序列不必只构造成一个“前 255 个事件预测第 256 个事件”的样本。这里有三种不同的训练合同：

```text
只监督末位：
L_last = -log p(e_256 | e_1, ..., e_255)

监督全部有效位置：
L_all = Σ_(t=1)^255 w_t [-log p(e_(t+1) | e_1, ..., e_t)]

采样若干截断点：
L_sample = Σ_(t∈S) w_t [-log p(e_(t+1) | e_1, ..., e_t)]
```

因果 Transformer 通常采用第二种方式：输入仍是 `e_1 ... e_255`，标签整体右移为 `e_2 ... e_256`，通过因果 attention mask 在一次前向中并行得到最多 255 个下一事件监督。选择 `e_1 ... e_99` 预测 `e_100`，属于第三种前缀采样；它不是与长序列建模互斥的另一种模型。

只监督末位通常不是模型的硬限制，而是数据合同的选择。如果每个窗口都锚定一次真实决策请求，只有末位事件属于目标总体；把中间事件全部加入损失会改变目标时点分布，也会让事件更多的主体获得更高权重。

| 训练合同 | 优点 | 缺点 |
|---|---|---|
| 只监督末位 | 与“窗口末端做一次判断”的推理接口一致；每个主体只贡献一个目标，样本权重简单 | 浪费中间 254 个可用目标；目标偏向窗口尾部；短历史状态训练不足 |
| 全位置监督 | 一次前向复用全部前缀；监督密度高；模型同时学习短、中、长历史 | 相邻目标高度相关；长序列或高活跃主体贡献更多损失；早期短前缀可能缺少上下文 |
| 随机前缀采样 | 控制每个主体的目标数；覆盖不同历史长度；可使训练长度分布接近线上 | 重叠前缀会增加数据与计算；采样方差更大；若只采短前缀会丢失长期依赖 |

“前 99 个预测第 100 个”主要有四个好处：

- 一条长序列可以产生更多训练时点，提高标签利用率；
- 模型会看到不同历史长度，减轻只会处理最长前缀的问题；
- 截断点可以对齐真实在线决策时刻，而不是人为固定在窗口末端；
- 可以对稀有事件或关键时间段提高采样率。

它的代价是：

- 只使用 99 个历史事件时，无法学习需要更长上下文的依赖；
- 同一主体的大量重叠前缀高度相关，可能让高活跃主体主导训练；
- 把所有截断前缀物化为独立样本，会增加存储、padding 和重复计算；
- 如果训练只用短前缀，而线上输入接近 255 个事件，会形成上下文长度分布偏移。

默认做法不是在 `99 → 100` 与 `255 → 256` 中二选一。因果模型可先对全部有效位置计算右移标签损失，再按主体、事件频率或时间位置设置权重；算力受限时，每轮为每条序列采样少量短、中、长截断点，并保留末端截断点。训练前缀长度分布应尽量覆盖线上分布，同时限制单个高活跃主体的总权重。

#### GRU 的实现差异

GRU 同样可以用全部时间步预测下一事件：

```text
h_t = GRU(e_t, h_(t-1))
logits_t = Head(h_t)
target_t = e_(t+1)
```

一次展开得到 `h_1 ... h_255` 后，可以把所有有效隐藏状态投影成下一事件 logits，并对右移标签计算损失。GRU 的状态更新按时间串行，不能像 Transformer 那样并行计算各时间步的主干；但输出头和全部位置的损失仍可按张量批量计算。

若只用最后状态 `h_255` 预测 `e_256`，计算图仍经过前 255 个事件，却只有一个直接监督信号。这样更贴近“窗口末端一次判断”，但监督较稀疏，早期状态主要通过长距离梯度间接学习。对全部 `h_t` 加监督可提供更短的梯度路径，通常更利于下一事件建模，但需要控制高活跃主体和相邻目标的重复权重。

随机生成 `99 → 100`、`159 → 160` 等独立前缀时，如果每个前缀都重新运行 GRU，会重复计算共享历史。更高效的方式是在一次完整展开中直接选取对应的 `h_99`、`h_159` 和 `h_255` 计算损失。只有当前缀的特征构造、状态初始化或增强不同，才需要独立前向。

前缀截断还应与 truncated BPTT 区分：

- **前缀截断**决定模型看到多少历史，以及哪些位置作为目标；
- **truncated BPTT**可以继续传递隐藏状态，但在分块边界停止梯度，用于限制显存和反向传播长度。

因此，GRU 的默认选择仍可采用全位置右移标签；若目标只在真实决策时点定义，则只监督合法时点。长序列显存受限时，再用 stateful truncated BPTT 控制梯度跨度，而不是把它误当成随机前缀采样。

### 离线通用表征

建议首版使用：

```text
字段级掩码恢复 + 同主体同状态子窗口对比
```

掩码恢复保留局部内容，子窗口对比约束全局表示。正样本必须限制在同一预测截止点或可证明状态一致的窗口内；负样本应排除同实体、近重复轨迹和已知同状态样本。

若同时使用 7 天、30 天、90 天等多尺度统计目标，各窗口必须共享同一个右端截止时点。由于嵌套窗口存在确定性包含关系，优先预测近期增量、相对长窗的残差或趋势，而不是直接复制长窗总量；否则模型可能通过窗口算术完成代理任务，却没有学到状态变化。

### 连续时间异常

建议首版使用：

```text
事件内容恢复 + 下一时间差 + 空区间或强度目标
```

等待时间本身可能是风险信号。训练和评估都应保留真实时间间隔，避免只用序列位置替代时间。

## 推荐的最小实验

先固定同一编码器、数据窗口和训练预算，只改变目标：

| 实验 | 目标 | 目的 |
|---|---|---|
| A | 仅掩码恢复 | 测局部内容保留 |
| B | 仅下一事件与时间 | 测因果动态建模 |
| C | 仅子序列对比 | 测主体级全局结构 |
| D | 掩码恢复 + 对比 | 检查局部与全局是否互补 |
| E | 下一事件与时间 + 对比 | 检查在线状态与稳定属性是否互补 |
| F | 最佳自监督目标 + 下游监督 | 判断预训练是否超过同预算从头训练 |

验收至少包含冻结线性探针、浅层 MLP、k-NN 或检索、全量微调、时间外切片、低标签比例、稀有风险类型和校准。线性探针用于检查信息是否以低复杂度方向保留，不是唯一充分标准。若联合目标只改善随机切分或二维可视化，不足以证明可部署价值。

输入打乱后下游指标下降只说明模型依赖顺序。还需通过合法重排、路径型风险切片和时间外数据验证这种顺序依赖确实有用，而不是依赖位置、长度或采集系统捷径。

## 关键风险

### 未来泄漏

- 目标事件仍出现在输入或统计特征中；
- 时间差按最终决策时点而非当前前缀计算；
- 双向编码结果被当作在线因果表示；
- 正样本视图跨越风险发生后的状态。

### 预训练捷径

- 重复事件在未遮蔽位置直接暴露答案；
- 模型只识别来源、序列长度、padding 或数据版本；
- 热门事件和热门对象主导恢复与负采样；
- 时间戳或缺失模式泄漏采集系统而非行为状态。

### 错误不变性

- 删除关键稀有事件后仍强制两视图相似；
- 重排方向敏感的交易或关系事件；
- 把具有相同高频下一行为的不同风险轨迹拉近；
- 把同一主体跨阶段的窗口无条件设为正样本。

## 证据边界

直接面向欺诈、反洗钱和恶意用户检测的公开研究数量仍少于推荐序列研究。本文把推荐系统和通用事件流方法作为目标结构的邻域证据，不把其指标提升外推为风控收益。

UB-PTM 与 CLeAR 的完整正文在本轮检索中未能稳定获取，因此只引用正式论文页公开的任务粒度，不补写公式。SOHET 和 PANTHER 与生产风控较接近，但各自结论仍需要在本地数据、时间切分和强基线下复现。
