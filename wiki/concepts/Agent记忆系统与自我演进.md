# Agent 记忆系统与自我演进

> 关联来源：[[来源-Agent记忆综述-2026]]

## 核心命题

随着 LLM Agent 进入「下半场」——任务从短提示走向长程、动态、用户依赖的真实场景（agentic coding、deep research、computer use）——**记忆**不再只是被动存储，而是 Agent **自我演进与长时可用性**的承载层。固定上下文窗口无法容纳爆炸式交互历史，能否"累积、管理、选择性复用"经验，决定了 Agent 在现实中的真实效用。

[[来源-Agent记忆综述-2026]] 给出的统一视角是：记忆系统应被当作**可设计、可优化、且越来越可学习**的能力来对待，而不是"挂一个向量库"就结束。

## 三维分类法

### 1. 记忆基底（Substrate）——以什么形式存在

| 基底 | 代表形态 | 优势 | 代价 |
|------|---------|------|------|
| **外部记忆** | 向量索引 / 文本记录 / 结构化存储 / 分层存储 | 可扩展、易更新、跨会话持久 | 检索延迟、依赖索引质量、随规模引入噪声 |
| **内部记忆-权重** | 预训练/后训练/模型编辑/蒸馏 | 访问快、与推理紧耦合 | 更新昂贵、易灾难性遗忘 |
| **内部记忆-隐状态** | 跨步复用 hidden states | 会话内连贯 | 不持久、随序列长度线性增长 |
| **内部记忆-KV Cache** | 注意力键值缓存 | 加速自回归解码 | 显存开销大、需压缩（heavy-hitter 驱逐等） |

**工程取舍**：内部记忆"快但贵且易忘"，外部记忆"可扩展但检索质量敏感"。实际系统多为**混合基底**：稳定通用知识沉淀进权重，动态/用户特定信息走外部存储，会话内状态用 KV cache/隐状态。

### 2. 认知机制（Cognitive Mechanism）——如何起作用

借用人类认知五类：**感觉 / 工作 / 情景 / 语义 / 程序**记忆。

关键洞见在于**闭环**：工作记忆"守门"决定哪些经验被感知、筛选、抽象进入活动上下文；长期记忆累积并固化为可复用知识与技能。短期与长期系统的**交互**（而非任一单点）构成 Agent 从经验中改进的回路——这与 [[可信图神经网络]] 中"多目标耦合而非单点优化"是同构的治理观。

### 3. 记忆主体（Subject）——为谁服务

- **用户中心**：个性化、画像与偏好记忆。
- **Agent 中心**：自身经验与技能累积。

## 从静态机制到可学习策略

记忆管理的**学习策略**形成谱系，这是该综述区别于既有工作的核心主张：

1. **Prompt 驱动**：静态提示 → 动态提示控制。
2. **微调参数化策略**：将策略内化进参数，并做稳定性/边界/检索精修。
3. **强化学习驱动**：step-level 记忆决策（什么写入、什么保留、什么遗忘、什么检索）。

技能进一步**外化**为显式、可移植、可分享的形式，经 agent harness / context engineering / 标准化工具中介协议暴露——这与 [[流量风控技能栈与Agent治理]] 的"技能栈治理"形成直接映射：Agent 的可审计能力，正落在记忆与技能的"可外化、可治理"上。

## 单 Agent vs 多 Agent 记忆操作

- **单 Agent**：基础的存储/检索/更新/遗忘操作。
- **多 Agent**：在协作/竞争/混合拓扑下的**记忆路由**——谁的记忆、如何共享、如何隔离。

这与 [[多Agent系统研究趋势与工程映射]] 的"协作拓扑 → 工程编排"映射呼应：拓扑选择直接决定记忆路由设计。

## 六大开放挑战

1. 持续学习与自我演进 Agent。
2. 多 Human-Agent 记忆组织。
3. 记忆基础设施与效率。
4. **终身个性化与可信记忆**。
5. 多模态/具身/世界模型 Agent 的记忆。
6. 真实世界评测（脱离静态 QA）。

## 与既有结论的关系

- 与 [[可信图神经网络]] 类比：两者都强调"从方法性能转向系统治理"；记忆的"可信"维度（可审计、隐私、遗忘可控）对应可信 GNN 的鲁棒性/隐私/问责维度。
- 与 [[多Agent系统研究趋势与工程映射]] 互补：综述把多 Agent 记忆路由作为系统设计变量，呼应本仓库"协作拓扑工程化"主轴。
- 与 [[Agent框架选型与工程维度]] 一致：可观测、可回滚、可治理的上线能力，在记忆维度具体化为"可审计的记忆与技能外化"。
