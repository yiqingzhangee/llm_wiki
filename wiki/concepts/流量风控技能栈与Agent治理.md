# 流量风控技能栈与Agent治理

> 基于 [[来源-搜索归档-流量风控skills-2026-06-20]] 的归纳，聚焦“流量反作弊”向“Agent 调用链治理”的扩展。

## 核心问题

在 Agent 参与业务后，风控目标不再只是“识别无效点击”，而是识别并治理**自动化调用链中的异常行为**：
- 谁在调用（主体识别）
- 调用了什么（API/工具行为）
- 调用是否偏离基线（异常检测）
- 是否可追溯与可处置（治理闭环）

## 技能栈分层

### 1) 识别层（Who）

- Agent 指纹识别：UA、TLS 指纹、来源账号、调用时序。
- 设备与网络信号：模拟器、多开、设备农场、群控、云手机、HOOK 等。

### 2) 行为层（What/How）

- 行为基线建模：接口集合、频率窗口、参数结构、调用链顺序。
- 异常检测：新接口突现、频率激增、参数结构漂移、调用链跳步。

### 3) 处置层（So what）

- 实时处置动作：降速、限流、二次验证、阻断、审计打点。
- 运营动作：高风险 skills 降权/下线，低风险通道放量。

### 4) 治理层（Can we trust it）

- 全链路追溯：从入口参数到安装/激活/付费回调可还原。
- 归因重构：区分“真实用户路径”与“代理路径”，避免数据黑洞。

## 对抗样本分层防御（新增）

> 关联来源：[[来源-对抗样本生成与检测调研实验-2026-06-21]]、[[来源-对抗图像样本生成原理与实践-2026-06-23]]
> 概念深化：[[对抗样本攻击原理与实践]]（含攻击 ASR 实测数据与防御量化结果）

围绕“看不见”与“看得见但判错”两类风险，建议按攻击面分层治理：

1. **视觉前处理层（优先拦截不可见攻击）**
   - 目标：缓解通道渲染、隐藏文本、分辨率欺骗等问题。
   - 方法：多尺度预处理、对比增强、结构恢复与分割辅助（如 SegFormer 路线）。
   - 产出信号：预处理前后判定差值、可疑区域热度、隐藏文本召回提升幅度。

2. **判别模型层（减少“看得见但判错”）**
   - 目标：提升语义伪装与结构化变换样本的稳健判定。
   - 方法：监督微调、困难样本重加权、规则与模型联合判定。
   - 产出信号：攻击家族分桶后的 FN/FP 变化、人审翻转率变化。

3. **策略与处置层（把鲁棒性接入业务闭环）**
   - 目标：让鲁棒性提升转化为可执行治理动作。
   - 方法：高风险流量二次验证、灰度阈值调节、异常样本回流训练。
   - 产出信号：平均处置时延、追溯完整率、回流样本复用率。

> 边界说明：当前结论主要来自 E2-E3 证据，跨模型泛化与线上收益仍需统一实验口径验证。

## 与传统流量反作弊的差异

- 传统反作弊更偏“单点事件识别”。
- Agent 治理更偏“链路级行为治理 + 插件供应链治理”。
