# 可信图神经网络

> 关联来源：[[来源-可信图神经网络综述-2022]]

## 核心命题

“可信图神经网络（Trustworthy GNNs）”不是单纯追求更高任务精度的 GNN，而是在图学习系统中同时纳入**鲁棒性、可解释性、隐私、公平性、问责、环境福祉**等治理要求，使模型具备可部署、可追责、可平衡取舍的现实可用性。

## 六大可信维度

### 1. 鲁棒性

- 关注图结构扰动、特征扰动、对抗攻击下的预测稳定性。
- 对高风险业务的意义：推荐操纵、欺诈绕过、图结构投毒都可能直接破坏线上决策。

### 2. 可解释性

- 关注模型为何给出某个节点/边/图级别预测。
- 可分为自解释模型与事后解释器两类。
- 在风控、授信、药物发现等场景中，解释能力决定结果是否能进入人工复核与责任链路。

### 3. 隐私

- 关注图数据、节点关系、模型参数中的敏感信息泄漏。
- 常见风险包括模型提取、成员推断、模型逆向，以及联邦/差分隐私方案带来的精度权衡。

### 4. 公平性

- 关注图结构与消息传播是否放大群体偏见。
- 比 tabular 场景更复杂，因为图里的连边关系会把局部偏差扩散成系统偏差。

### 5. 问责

- 不只要求“能评估”，还要求开发、训练、验证、上线全过程可审计。
- 包括：认证流程、日志留痕、违规检测、人类干预与补救机制。

### 6. 环境福祉

- 关注能效、算力占用、可扩展性与部署成本。
- 大图训练、复杂采样和硬件瓶颈都属于这一维度。

## 一个更实用的理解：可信 = 多目标系统治理

可信 GNN 的关键不在“多列几个指标”，而在于承认这些目标会**互相牵制**：

- 更强鲁棒性可能提高训练/推理成本；
- 更强隐私保护可能损失精度；
- 更严格公平约束可能改变可解释路径；
- 更高问责要求会增加工程复杂度与日志成本。

因此，可信 GNN 更接近“治理问题”，而不是“模型 patch 问题”。

## 与本仓库既有主题的映射

### 与 [[流量风控技能栈与Agent治理]] 的关系

两者都在回答同一个问题：**高能力模型如何安全上线。**

- 可信 GNN 强调图学习系统的六维治理；
- 风控技能栈强调调用链、审计、处置与回流训练的闭环。

可把两者对应理解为：

| 可信 GNN 维度 | 风控/治理中的近似映射 |
|---|---|
| 鲁棒性 | 对抗防御、绕过检测、异常流量识别 |
| 可解释性 | 归因、人工复核、误杀复盘 |
| 隐私 | 敏感关系保护、日志脱敏 |
| 公平性 | 规则/模型是否系统性偏置特定群体 |
| 问责 | 审计链路、责任归属、处置记录 |
| 环境福祉 | 推理成本、扩缩容效率、线上资源治理 |

### 与 [[多Agent系统研究趋势与工程映射]] 的关系

两页都体现一个共同趋势：研究界关注点正在从“能不能做”转向“如何治理上线”。区别仅在对象不同：

- 可信 GNN 面向图学习系统；
- 多 Agent 映射页面向协作型智能体系统。

## 当前最值得保留的结论

1. **可信不是附加项，而是设计哲学转变。**
2. **问责与统一评估协议是落地最大短板之一。**
3. **不同可信维度之间存在促进/抑制关系，必须显式权衡。**
