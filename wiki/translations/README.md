# 全文译文目录（`wiki/translations/`）

本目录存放**非简体中文全文**（文章、论文、长文）的**逐句简体中文译文**页，与根目录 `CLAUDE.md` **全局规则第 3 条**一致。

## 约定

- **唯一位置**：全文译文**只**放在本目录，**不**放在 `wiki/sources/`。
- **命名**：`<描述性 stem>-全文译文.md`，其中 `stem` 与对应 `wiki/sources/来源-<stem>.md` 去掉前缀 `来源-` 后的部分一致（便于交叉链接）。
- **每页须含**：指向 `raw/` 的链接、指向 `wiki/sources/来源-*.md` 的链接；译文正文按原文顺序**逐句**补全。
- **原文已是简体中文**：无需「英译中」全文时，可建**说明页**（见本目录下 CCL 2024 对应文件），避免与英文综述占位混淆。

## 历史综述专项

`raw/articles/` 既有七篇与 `wiki/sources/来源-*.md` 对齐；英文六篇的译文正文在专项摄入中**分批补全**，未完成前请以 `raw/` 与对应「分节详解」为准。
