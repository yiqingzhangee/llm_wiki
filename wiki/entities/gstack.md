# GStack

**类型**：开源 **Claude Code 扩展栈**（技能 + 斜杠命令 + 安装脚本）。

**作者 / 公开介绍**：Garry Tan（据上游 README）；仓库 [garrytan/gstack](https://github.com/garrytan/gstack)。

**本地镜像（只读）**：`raw/code/gstack/`

## 作用

将大量**结构化工作流**打包给 Claude Code 使用 — 规划、多角色评审、对线上 URL 做 QA、设计走查、安全审查、发布、复盘等，便于个人或小团队标准化「代理辅助」的研发流程。
