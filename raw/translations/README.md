# 全文译文归档（`raw/translations/`）

本目录存放非简体中文文章、论文和长文的逐句简体中文译文，以及原文已为简体中文时的对应说明页。译文作为原始材料的受控归档，相关 Wiki 来源页负责提供摘要、概念织入与导航。

## 约定

- **归档位置**：全文译文只放在本目录，不放入 `wiki/sources/`；对应来源页以链接提供入口。
- **命名**：`<描述性 stem>-全文译文.md`；名称与对应来源页保持可辨识的对应关系。
- **链接**：每页应指向对应原文与 Wiki 来源摘要；译文正文按原文顺序逐句补全。
- **原文已是简体中文**：可保留说明页，避免与尚待翻译的英文资料混淆。
- **维护权限**：`raw/` 默认由人类维护；新增、修订或迁移本目录内容须由人类放置，或由人类明确要求代理执行，不构成对 `raw/` 的一般写权限。

## 历史综述专项

`raw/articles/` 中有七篇与 Wiki 来源摘要对齐；英文六篇的译文正文按专项批次补全，未完成前请以原文及对应分节详解为准。
