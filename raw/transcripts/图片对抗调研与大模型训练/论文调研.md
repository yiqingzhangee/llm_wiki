### InstaGen: Enhancing Object Detection by Training on Synthetic Dataset

 用diffusion生图，同时在 diffusion 模型里加一个 **instance-level grounding head，** 生成图像的同时 **知道每个目标在哪里（bbox / mask）**，避免了 synthetic data 没有标注 / 标注不准的问题



### Synthetic Dataset Generation for Adversarial Machine Learning Research

#### 解决痛点（和我们业务问题很接近）：

- 真实对抗样本（adversarial / harmful / bypass）**稀缺且不可控**

-  数据分布不均，**难以系统评估防御边界**

-  很多 defense 只在"已知攻击"上有效，**泛化很差**

#### 目标：

- 构建一个 **可参数化（parameterizable）+ 可扩展（scalable）+ 自动生成（automated）** 的 synthetic dataset pipeline

#### 方法

控制变量：perturbation 强度 、 可见性（透明度 / 尺度） 、 语义偏移程度（加扰动 -> 接近其他类）



### Efficient Black-box Adversarial Attacks via Bayesian Optimization Guided by a Function Prior

- **黑盒**攻击者无法获取目标模型的内部参数（如梯度），只能通过不断的"查询-反馈"来生成对抗样本。**痛点**：现有的黑盒攻击方法（如基于查询的攻击）往往需要数千次查询才能成功，效率低下。虽然有些方法利用"替代模型"的梯度来加速，但局部梯度信息有限，无法提供全局指导。

- 提出了一种名为 **P-BO**的算法。不同于以往只利用局部梯度，P-BO 将替代模型（Surrogate Model）作为**全局函数先验**引入到贝叶斯优化中。利用高斯过程（Gaussian Process）来建模攻击目标函数，并将替代模型的损失函数初始化为高斯过程的**均值函数**。为了防止因为替代模型与目标模型差异过大（坏先验）导致攻击失败，作者设计了一种自适应调整系数，动态权衡先验信息和实际查询反馈。
