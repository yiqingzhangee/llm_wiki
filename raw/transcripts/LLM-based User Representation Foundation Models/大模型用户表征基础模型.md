### 论文 11 · FOUNDv2：面向用户表征的统一量化 Tokenizer

**中文标题**：FOUNDv2：面向用户表征的统一量化 Tokenizer 学习

- **发表信息**：KDD 2026
- **arXiv 编号**：2508.00956（2025-08 预印本版本）
- **作者**：Chuan He、Yang Chen、Bin Dou（共同一作），Wuliang Huang，**Baokun Wang（通信作者）**，Yongchao Liu，Xing Fu，Yu Cheng，Chuntao Hong，Weiqiang Wang，Zhongle Xie，Jiajun Zheng，Xin-Wei Yao
- **署名身份**：**通信作者**

**中文摘要**：论文针对连续型用户 embedding 的三大痛点——**缺乏多源数据统一整合范式**、**信息密度低导致存储开销高**、**缺乏多尺度粒度建模能力**，提出 FOUNDv2。其核心是两阶段 **U²QT（Unified User Quantized Tokenizer）**框架：先在异构用户数据（交易、行为、属性、图关系）上抽取行为语义特征，再将其映射到统一的**离散 token 词表**。下游任务把用户视作 user-token 序列，与语言 token 保持接口一致，可以复用主流 LLM 的训练与推理基础设施。该方案是 FOUND 系列基础模型的**第二代**。

### 论文 12 · Query as Anchor：基于 LLM 的场景自适应用户表征

**中文标题**：Query 即锚点：基于大语言模型的场景自适应用户表征

- **发表信息**：KDD 2026
- **arXiv 编号**：2602.14492
- **作者**：Jiahao Yuan、Yike Xu（共同一作，其中 Jiahao 为蚂蚁实习期间完成），Jinyong Wen，**Baokun Wang（通信作者）**，Ziyi Gao，Xiaotong Lin，Yun Liu，Xing Fu，Yu Cheng，Yongchao Liu，Weiqiang Wang，Zhongle Xie
- **署名身份**：**通信作者**

**中文摘要**：现有用户 embedding 大多是**静态、与任务无关**的，难以同时满足推荐、圈选、风控等下游场景的差异化需求。本文把用户建模重构为「**Query 感知的动态合成**」，主要贡献有三：

1. **UserU 数据集**：构建支付宝级预训练数据集，将多模态行为序列与用户理解语义显式对齐；
2. **Q-Anchor 架构**：在双塔 LLM 中嵌入层次化 coarse-to-fine 编码器，用**对比 + 自回归联合目标**训练场景可感知的用户表征；
3. **Cluster-based Soft Prompt Tuning**：把预训练与业务逻辑对齐，让模型注意力聚焦到场景特定模态。

工程上，将锚点 query 放在序列末端可以复用 KV-cache 加速推理，几乎不引入额外延迟。在 10 个支付宝工业基准上取得 SOTA，并在两个真实业务场景通过大规模线上 A/B 验证。代码计划开源：`https://github.com/JhCircle/Q-Anchor`。

### 论文 13 · 迈向十亿规模下用户表征学习的 Densing Law

**中文标题**：迈向十亿规模用户表征学习的致密律（Densing Law）

- **发表信息**：arXiv 2608.23392（2026-08）
- **作者**：Bin Dou、Junru Zhang、Zhaoyi Yuan（共同一作），Wuliang Huang，Letian Gong，**Baokun Wang（通信作者）**，Huan Li（浙大侧通信作者），Yu Cheng，Weiqiang Wang（蚂蚁 DeepFind Team + 浙江大学联合）
- **署名身份**：**通信作者**

**中文摘要**：论文首先定义并观测到**「原始行为 scaling 墙 (raw behavioral scaling wall)」**：直接扩大用户量、行为窗口或编码器规模后，下游收益迅速衰减，出现「预训练 loss 继续下降、下游精度停滞」的**损失-质量脱耦**现象。原因在于用户行为日志高度重复，新增数据几乎不带来新的任务相关信息。

在此基础上，作者提出**用户行为致密律（User Behavioral Densing Law）**，从理论与十亿级支付宝 PayBill 实验两个维度，刻画「数据规模 ↔ 最小充分 tokenization 容量」的定量关系。基于该规律进一步设计新 tokenization 方法 **ALGN**，在多个数据源、多种 tokenization 基线与多个下游任务上，兼具效果与效率优势，为大规模用户表征学习提供了配置选择的方法论依据。

### 论文 14 · Decoder-Only LLM 如何感知用户？

**中文标题**：Decoder-Only LLM 如何感知用户？——重新思考用户表征中的注意力掩码

- **发表信息**：arXiv 2602.10622（2026-02）
- **作者**：Jiahao Yuan、Yike Xu（共同一作，Jiahao 为华东师大蚂蚁实习期间完成），Jinyong Wen，**Baokun Wang（通信作者）**，Yang Chen，Xiaotong Lin，Wuliang Huang，Ziyi Gao，Xing Fu，Yu Cheng，Weiqiang Wang
- **署名身份**：**通信作者**

**中文摘要**：把 decoder-only LLM 用作用户编码器已经成为一种流行做法，但**注意力掩码策略对用户 embedding 质量的影响尚未被系统研究**。本文在统一的对比学习框架下，基于支付宝真实长历史异构行为数据，系统对比三类掩码：因果 (causal)、混合 (hybrid)、双向 (bidirectional)。

主要发现是「**因果 → 双向的训练过渡本身**」显著影响优化稳定性与最终表征质量。为此提出 **Gradient-Guided Soft Masking (GG-SM)**：在切换到双向掩码之前，用梯度信息做「预热」，让未来位置的注意力权重在优化过程中平滑打开，配合线性调度器一起使用。在 9 个覆盖预测、偏好、营销敏感度的用户理解基准上，GG-SM 一致优于纯因果、混合、纯 scheduler 三类基线，且不破坏 decoder 预训练能力。代码开源：`https://github.com/JhCircle/Deepfind-GGSM`。

### 论文 15 · Transferable and Forecastable User Targeting 基础模型

**中文标题**：可迁移、可预测的用户圈选基础模型

- **发表信息**：WWW 2025 Companion Proceedings（DOI: 10.1145/3701716.3715266）
- **作者**：Bin Dou（蚂蚁实习期间完成），**Baokun Wang（通信作者）**，Yun Zhu，Xiaotong Lin，Yike Xu，Xiaorui Huang，Yang Chen，Yun Liu，Shaoshuai Han，Yongchao Liu，Tianyi Zhang，Yu Cheng，Weiqiang Wang，Chuntao Hong
- **署名身份**：**通信作者**

**中文摘要**：把用户圈选（预测哪些用户会在给定活动中转化）从传统的「一场景一模型」升级为**基础模型范式**。训练一个统一模型，同时具备两大能力：

- **可迁移 (Transferable)**：跨营销场景复用同一套用户表征，无需为每个活动单独重训；
- **可预测 (Forecastable)**：对未来目标人群规模与响应率做前瞻性预测，服务于活动规划。

已在支付宝营销投放链路规模化落地。

### 论文 16 · 指令感知用户 Embedding：语言与表征协同建模

**中文标题**：基于语言与表征协同建模的指令感知用户 Embedding

- **发表信息**：arXiv 2510.11016（2025-10）
- **作者**：Ziyi Gao、Yike Xu、Jiahao Yuan、**Baokun Wang**、Jinyong Wen、Xiaotong Lin、Yun Liu、Xing Fu、Yu Cheng、Yongchao Liu 等
- **署名身份**：合著者

**中文摘要**：让用户 embedding 具备「**指令感知**」能力：同一份用户历史，在不同下游 instruction / prompt 下产出**差异化 embedding**（例如「是否点击优惠券」vs「是否订阅服务会员」两类任务的用户表示应有所不同）。方法上，在同一个模型架构内**协同训练语言建模目标与用户表征目标**，让多个下游任务共享一个用户塔，避免为每个业务任务单独维护一套用户编码器，大幅降低工程与训练成本。

## Thread 3 — LLM-based User Representation Foundation Models

Baokun Wang is one of the technical leads for the DeepFind Team, building large-scale user-representation foundation models that power Alipay's recommendation, targeting, risk-control and marketing pipelines. He is corresponding author on multiple pillar papers of this line.

---

### 11. FOUNDv2: Learning Unified User Quantized Tokenizers for User Representation

- **Venue**: KDD 2026
- **arXiv**: 2508.00956 (2025-08 preprint)
- **Authors**: Chuan He, Yang Chen, Bin Dou (co-first), Wuliang Huang, **Baokun Wang** (Corresponding), Yongchao Liu, Xing Fu, Yu Cheng, Chuntao Hong, Weiqiang Wang, Zhongle Xie, Jiajun Zheng, Xin-Wei Yao
- **Role**: Corresponding author

**Summary**: Addresses three limitations of continuous user embeddings — the lack of a unified paradigm for multi-source integration, prohibitive storage overhead due to low information density, and the lack of multi-scale granularity. FOUNDv2 introduces a two-stage U²QT (Unified User Quantized Tokenizer): it first extracts multi-source behavioral signals, then quantizes them into a shared discrete token vocabulary, so downstream tasks can consume users as sequences of user-tokens analogous to language tokens. The scheme unlocks the second-generation FOUND user foundation model.

---

### 12. Query as Anchor: Scenario-Adaptive User Representation via Large Language Model

- **Venue**: KDD 2026
- **arXiv**: 2602.14492
- **Authors**: Jiahao Yuan, Yike Xu (co-first, intern), Jinyong Wen, **Baokun Wang** (Corresponding), Ziyi Gao, Xiaotong Lin, Yun Liu, Xing Fu, Yu Cheng, Yongchao Liu, Weiqiang Wang, Zhongle Xie
- **Role**: Corresponding author

**Summary**: Existing user embeddings are usually static and task-agnostic, making it hard to reconcile the divergent needs of different downstream scenarios (recommendation, targeting, risk). Query-as-Anchor reframes user modeling as query-aware dynamic synthesis: (1) UserU, an Alipay-scale pre-training dataset that aligns multi-modal behavior sequences with user-understanding semantics; (2) Q-Anchor architecture — hierarchical coarse-to-fine encoders inside dual-tower LLMs, jointly optimized by contrastive and autoregressive losses; (3) Cluster-based Soft Prompt Tuning for scenario alignment. Anchoring queries at sequence tail allows KV-cache-accelerated inference. Achieves SOTA on 10 Alipay industrial benchmarks and passes online A/B tests in two production scenarios.

---

### 13. Towards a Densing Law for User Representation Learning at Billion-Scale Capacity

- **Venue**: arXiv 2608.23392 (2026-08)
- **Authors**: Bin Dou, Junru Zhang, Zhaoyi Yuan (co-first), Wuliang Huang, Letian Gong, **Baokun Wang** (Corresponding), Huan Li (Corresponding, ZJU), Yu Cheng, Weiqiang Wang (DeepFind Team, Ant Group + Zhejiang Univ.)
- **Role**: Corresponding author

**Summary**: Identifies a "raw behavioral scaling wall" — scaling raw user sequences, user population or encoder size soon hits diminishing returns because behavioral logs are dominated by daily repetition. The paper formalizes a User Behavioral Densing Law that quantitatively relates data scale to the minimum sufficient tokenization capacity, backed by both theory and billion-scale Alipay PayBill experiments. Also proposes a new tokenization method ALGN inspired by the Densing Law, which outperforms baselines on both effectiveness and efficiency.

---

### 14. How Do Decoder-Only LLMs Perceive Users? Rethinking Attention Masking for User Representation Learning

- **Venue**: arXiv 2602.10622 (2026-02)
- **Authors**: Jiahao Yuan, Yike Xu (co-first, intern), Jinyong Wen, **Baokun Wang** (Corresponding), Yang Chen, Xiaotong Lin, Wuliang Huang, Ziyi Gao, Xing Fu, Yu Cheng, Weiqiang Wang
- **Role**: Corresponding author

**Summary**: Systematically studies causal / hybrid / bidirectional attention masks when adapting decoder-only LLMs as user encoders, within a unified contrastive learning framework trained on large-scale Alipay data. Proposes Gradient-Guided Soft Masking (GG-SM), a gradient-informed pre-warmup applied before a linear scheduler that gradually opens future attention during optimization, stabilizing the transition from causal to bidirectional attention. On 9 industrial user-cognition benchmarks (prediction, preference, marketing sensitivity), GG-SM produces more stable training and stronger bidirectional user embeddings than causal, hybrid, and scheduler-only baselines.

---

### 15. Transferable and Forecastable User Targeting Foundation Model

- **Venue**: WWW 2025 Companion Proceedings (DOI 10.1145/3701716.3715266)
- **Authors**: Bin Dou (Ant Group intern), **Baokun Wang** (Corresponding), Yun Zhu, Xiaotong Lin, Yike Xu, Xiaorui Huang, Yang Chen, Yun Liu, Shaoshuai Han, Yongchao Liu, Tianyi Zhang, Yu Cheng, Weiqiang Wang, Chuntao Hong
- **Role**: Corresponding author

**Summary**: Reframes user targeting (identifying users who will convert on a given campaign) from a "one model per scenario" pattern to a foundation-model paradigm. Trains a shared model that (i) transfers across marketing scenarios without per-campaign retraining, and (ii) forecasts future audience size and response rate for planning. Deployed in Alipay's marketing pipeline.

---

### 16. Instruction-aware User Embedding via Synergistic Language and Representation Modeling

- **Venue**: arXiv 2510.11016 (2025-10)
- **Authors**: Ziyi Gao, Yike Xu, Jiahao Yuan, **Baokun Wang**, Jinyong Wen, Xiaotong Lin, Yun Liu, Xing Fu, Yu Cheng, Yongchao Liu, et al.
- **Role**: Co-author

**Summary**: Trains a single user tower that produces different embeddings for the same user history conditioned on a downstream instruction (e.g., "will this user click a coupon vs. subscribe to a plan"). By co-training language modeling and user-embedding objectives inside one architecture, downstream tasks share a common backbone instead of maintaining separate task-specific user towers.

### 17. Learning Unified User Quantized Tokenizers for User Representation (FOUNDv2 arXiv preprint)

- **Venue**: arXiv 2508.00956 (2025-08)
- **Authors**: Chuan He, Yang Chen, Wuliang Huang, Tao Zheng, Jiajun Chen, Bin Dou, Yang Luo, Yun Zhu, **Baokun Wang**, et al.
- **Role**: Co-author (Corresponding on the KDD 2026 version)

**Summary**: The arXiv preprint that underlies the KDD 2026 FOUNDv2 paper (Item 11). Details the two-stage training of U²QT — behavioral feature extraction followed by discrete quantization — and reports consistency gains across offline profiling, online recommendation and risk-control tasks.
