# Qwen3-VL 事件序列编码器调研计划

## 目标

针对带固定英文事件描述、事件类型、时间戳和可选动态属性的变长事件序列，先确定最低工程成本的连续向量编码器，再评估是否将该向量加工成 Qwen3-VL-4B soft token。

## 背景与约束

- 复用统计特征方案：固定描述离线编码，在线链路不重复运行文本编码器。
- 序列编码器主接口输出 `[B, d_seq]` 连续向量；独立 projector 可选输出 `[B, M, 2560]` soft token。
- 最小 PoC 默认 `d_seq=128`、`M=1`；只有单 token 出现稳定容量瓶颈时才增加 token 数。
- 显式保留事件顺序、相邻时间间隔、距预测时点时间、缺失和动态属性。
- 数据处理遵守预测时点可用性、实体隔离、先切分后拟合与同一时间窗口。
- 保留 GRU、Transformer、文本模板、聚合统计和专用模型强基线。
- 不修改 `raw/`，不提交 `assets/`。

## 关键决策

| 决策 | 理由 | 日期 |
|---|---|---|
| 三个候选共享连续向量 + 可选 projector 接口 | 只比较序列编码器能力 | 2026-10-26 |
| 固定事件描述离线编码 | 避免逐样本文本开销，保留事件语义 | 2026-10-26 |
| 第一阶段冻结 Qwen3-VL | 降低训练成本与归因难度 | 2026-10-26 |
| TiSASRec 使用 ACM DOI | `arXiv:2002.00741` 是另一篇时间注意力论文 | 2026-10-26 |
| 最小方案采用单层 GRU | 对约 8 步序列保留顺序且实现、掩码和部署成本低 | 2026-10-26 |
| 连续向量与 soft token 解耦 | 同一序列表示可用于分类、晚融合或 Qwen 接入 | 2026-10-26 |
